Quick Check: Errors are [1, 1, 1, 1, 20]. Which metric is affected more by the single large error?

A. MAE    B. RMSE    C. Both equally    D. Neither

Answer: B. RMSE squares each error before averaging, so 20 becomes 400 — much bigger than the 1s. MAE: $(1+1+1+1+20)/5 = 4.8$. RMSE: $\sqrt{(1+1+1+1+400)/5} \approx 9.0$. Squaring amplifies large errors.

def find_nearest_1d(numbers, target):

def eliminate_pair(eq1, eq2, var_index):

def solve_equations(equations):
    if len(equations) == 1:
        return [equations[0][-1] / equations[0][0]]
    pivot = equations[0]
    reduced = []
    for i in range(1, len(equations)):
        reduced.append(eliminate_pair(pivot, equations[i], 0))
    rest = solve_equations(reduced)
    x1 = solve_for_first(pivot, rest)
    return [x1] + rest

import random

def weighted_choice(probabilities):
    r = random.random()
    cumulative = 0
    for i, p in enumerate(probabilities):
        cumulative += p
        if r < cumulative:

import math

def softmax(values):
    mx = max(values)
    exps = [math.exp(v - mx) for v in values]
    total = sum(exps)
    return [e / total for e in exps]

print(softmax([1, 2, 3]))
# [0.090, 0.245, 0.665]
print(softmax([1000, 1001, 1002]))  # same — no overflow!

Hint: subtract the max before exponentiating to avoid overflow. The ratios stay the same.
