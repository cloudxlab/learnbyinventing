# Circular Shift by One Write that moves every element one position to the left, with the first element wrapping around to the end — in place, with only one temporary variable: becomes .
# ---
Here's a puzzle that sounds simple but has a catch. Imagine a row of numbers, and you want every element to slide one spot to the left, with the first one wrapping around to the end. Easy if you make a whole new list. But here we want to do it in place, using just one temporary variable. Before you code anything, grab a pencil and think about which element you need to save first, and what happens if you don't. Give it a try yourself.
