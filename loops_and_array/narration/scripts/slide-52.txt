# Reverse, In Place Write that reverses the list without creating a new list — no , no , no second list. Walk two indices toward each other from the ends, swapping as you go. The function should modify and return nothing.
# ---
Now let's flip a list backwards, but with a twist: no new list allowed. You'll do it right inside the original, using two indices that start at opposite ends and walk toward each other, swapping as they go. Before you code, picture a short list on paper and trace the swaps by hand. Give it a try first.
