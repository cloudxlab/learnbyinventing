# Part 4: Polynomials A polynomial like [math] is stored as a list of coefficients in descending power order: . Index 0 = highest power; last index = constant term ([math]).
# ---
Polynomials are our next stop, and here's the neat trick. We can store one as just a list of numbers, its coefficients, with the highest power first. So the first spot holds the biggest power's coefficient, and the very last spot is always the plain constant. Keep that ordering in mind, because everything we build next depends on it.
