# Extract All Digits Given two tiny helper functions that pull apart a number one digit at a time: returns the rightmost digit chops off that digit Using these (plus a loop), write that returns a list of 's digits, in order. [code block]
# ---
Here's a fun puzzle: can you take a number apart, one digit at a time? We've got two tiny helpers. One peels off the rightmost digit, and the other chops that digit away. Put them together with a loop, and you can collect every digit in order. Think about when the loop should stop, and which end you're reading from. Give it a try!
