# Part 5: Solving Linear Equations A linear equation with N variables: [math] is stored as (coefficients then RHS). A system of equations is a list of such lists. You will build a recursive solver step by step.

Now we're moving into something that feels like real math: solving linear equations. Each equation is stored as a plain list, with the coefficients first and the answer on the right at the end. A whole system is just a list of those lists. We'll build the solver one small step at a time, and it'll turn out to be recursive.
