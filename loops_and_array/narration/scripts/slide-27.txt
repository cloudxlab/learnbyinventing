# Part 5: Solving Linear Equations A linear equation with N variables: [math] is stored as (coefficients then RHS). A system of equations is a list of such lists. You will build a recursive solver step by step.

Now we're moving into a new kind of problem: solving linear equations. You've probably seen these in algebra, where several equations share the same unknowns and you hunt for the values that satisfy all of them at once. Here, we'll store each equation as a simple list: the coefficients first, then the right-hand side. A whole system is just a list of those lists. We'll build the solver one small step at a time, so let's get started.
