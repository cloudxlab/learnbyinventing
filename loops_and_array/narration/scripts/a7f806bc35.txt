# Biased Coin Toss (70% Head) Write — Head 70% of the time, Tail 30%. Print / , return 0 / 1. After writing, run 1000 tosses and check that the fraction of heads is near 0.70.
# ---
Here's a fun one: you've probably flipped a fair coin before, but what if the coin were rigged? Your job is to write a function that lands Head seventy percent of the time and Tail thirty percent. Think about how you could get a random number and use it to split things unevenly. Once it works, run a thousand tosses and see if the fraction of heads lands near seventy percent. Give it a try before moving on!
