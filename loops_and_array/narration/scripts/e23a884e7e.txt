# ON SCREEN:
# Reverse, In Place Write that reverses the list without creating a new list — no , no , no second list. Walk two indices toward each other from the ends, swapping as you go. The function should modify and return nothing.
# ---
Here's a fun challenge: reverse a list without making a second one. No slicing, no reversed function, no extra list. Just the list you already have.

Think about two fingers, one at each end. What would you do with the two items they point at? Then what happens to the fingers?

Try working it out on a short list with pencil and paper first, then write your function. It changes the list directly and returns nothing.
