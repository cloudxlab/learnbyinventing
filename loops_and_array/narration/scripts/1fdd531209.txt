# ON SCREEN:
# Extract All Digits Given two tiny helper functions that pull apart a number one digit at a time: returns the rightmost digit chops off that digit Using these (plus a loop), write that returns a list of 's digits, in order. [code block]
# ---
Here's a challenge that ties together a lot of what you've learned. We've got two tiny helpers: one grabs the rightmost digit of a number, and the other chops that digit off. On their own they're simple, but put them inside a loop and you can pull a whole number apart, one digit at a time. Try writing it yourself first. Think about when the loop should stop, and what order the digits come out in.
