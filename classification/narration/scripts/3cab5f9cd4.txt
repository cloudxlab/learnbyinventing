Welcome to Part 4. So far we've been trying to turn a score into a probability, and we've run into the problem that a straight line can wander off below zero or above one. What we really want is a smooth function that takes any number, however big or small, and squeezes it neatly between zero and one. Before we look at anything, think about what shape that curve would need to have. Let's build it together.
