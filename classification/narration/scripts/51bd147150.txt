Time to level up. So far our model looked at just one input, but real problems have lots of features at once. Think about what changes. Instead of a single weight and a single input, you'll now have a weight for every feature. Give it a go yourself: write a predict function that takes all the features and all the weights, and combines them into one score. Pause here and try it before we move on.
