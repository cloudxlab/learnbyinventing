# Part 5: Is a Point Inside a Rectangle? (2D)

Now we're stepping up from a number line to a flat plane. Here's a question: is a point inside a rectangle? Before, you only had to check one direction. Now there are two, left-right and up-down. Think about how the one-dimensional ideas you already built might combine here. Give it some thought before we dive in.
