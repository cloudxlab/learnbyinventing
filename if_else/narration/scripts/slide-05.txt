# ON SCREEN:
# A Three-Way Branch / only gives you two outcomes. // gives you more. Write a function that takes a die result (1 through 6) and returns: if is 1 or 2 if is 3 or 4 if is 5 or 6 Tasks: Implement it using //. Roll the die 20 times with and classify each result. Print both the roll and its class.
# ---
Here's a puzzle: a die has six faces, but we only want three groups. An if-else only gives us two outcomes, so how do we get three? This is where integer division comes in. It chops off the remainder, and it can turn six different numbers into just a few different answers. Before you write any code, try it on paper. What do the numbers one through six give you? Then write the function, roll the die twenty times, and print each roll with its class.
