Now that we can measure the slope at any point, here's the big idea. Look at what the slope is telling us. If it's positive, the curve is climbing to the right. If it's negative, the curve is climbing to the left. And if it's zero, we're sitting right at the bottom.

So the slope is a signpost. Before we go on, think about it: which way should we step in each case if we want to go downhill?
