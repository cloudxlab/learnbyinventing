# ON SCREEN:
# For each point, the error is: prediction [math] actual [math]. But some errors are positive and some negative they cancel if you just add them. How would you fix the cancellation problem? Think of at least one way to make all errors positive before adding them.
# [Fragment 0]: Two common ideas: take the absolute value of each error, or square each error. Both work! Squaring is more common it penalizes large errors more heavily and is smoother (easier for gradient descent).
# ---
Both work! Absolute value just drops the sign, and squaring does the same thing. Squaring is the one you'll see most, because it punishes big mistakes harder and gives a smooth curve that gradient descent can slide down easily.
