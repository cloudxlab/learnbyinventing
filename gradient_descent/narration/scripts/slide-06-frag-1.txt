# Notice the shape it looks like a bowl . A function is convex if it curves upward everywhere. Visually: draw a straight line between any two points on the curve the curve always stays below that line.
# [Fragment 1]: A convex function has exactly one minimum no bumps, no extra dips. That s what makes it possible to find the bottom reliably.
# ---
That's what makes this shape so useful. With only one minimum and no bumps or extra dips, whenever we head downhill, we know we're heading toward the real bottom.
