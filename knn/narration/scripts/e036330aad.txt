# First we need a way to measure how far apart two points are. Write for any number of dimensions:
# ---
Before we can find the nearest neighbors, we need a way to measure how far apart two points are. That's the first building block. Here's the twist: your function should work for any number of dimensions, whether that's two features or twenty. Think about how you'd measure the gap along each feature, then combine those gaps into one number. Give it a try yourself.
