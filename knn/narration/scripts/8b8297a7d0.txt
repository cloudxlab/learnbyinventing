# Quick Check: K-NN s biggest weakness at scale is: A. It can only handle two classes B. It needs to be retrained when new data arrives C. It computes distance to every training point for each prediction D. It can only work with numbers, not categories
# [Fragment 0]: Answer: C. With [math] training points and [math] dimensions, each prediction costs [math]. For millions of points, that gets slow. (Techniques like KD-trees help.)
# ---
That's right, it's C! Every time you ask for a prediction, K-NN has to measure the distance to every single training point, and with millions of points, that adds up fast. The good news is that clever tricks like KD-trees can help speed it up.
