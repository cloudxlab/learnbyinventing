# Part 2: From 1 Neighbor to K Neighbors
# ---
We've been finding the closest point to a new example, and using its label as our prediction. That works, but it has a weakness. What if that single nearest neighbor is a bit of an oddball? One strange point could throw off the whole answer. So in this part, we'll ask a simple question: what if we let a few neighbors vote instead of just one?
