# Part 1: The Prediction Error Problem Imagine you're building a model that predicts house prices (in lakhs) for 5 different houses at a time. You want to compute the overall error of this model — a single number — so that you can try tweaking each individual weight and see how that weight impacts the overall error.

Picture this: you've built a model that guesses house prices, and it's looking at five houses at once. Each house gets its own prediction, and each one is off by a different amount. But to tweak your model's weights, you need just one number that says how wrong it is overall. That's the puzzle we're solving here. Let's invent that number together.
