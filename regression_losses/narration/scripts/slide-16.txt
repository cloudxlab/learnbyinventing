# Part 4: The Best of Both Worlds Here's our situation: Small errors Large errors Squared ([math]) Smooth, differentiable Gradient explodes Absolute ([math]) Not differentiable at 0 Gradient stays bounded (±1) What if we could use the squared loss for small errors (where it's well-behaved) and the absolute loss for large errors (where it stays bounded)?
# ---
Here's where we've landed. Squared loss is smooth and easy to work with, but when an error gets big, its gradient blows up. Absolute loss keeps the gradient steady, but it has that sharp corner right at zero.

So each one is good in one place and bad in another. What if we didn't have to choose? Think about using squared loss for small errors and absolute loss for big ones. Let's try inventing that.
