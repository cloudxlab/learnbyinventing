# Part 1: The Prediction Error Problem Imagine you're building a model that predicts house prices (in lakhs) for 5 different houses at a time. You want to compute the overall error of this model — a single number — so that you can try tweaking each individual weight and see how that weight impacts the overall error.
# ---
Let's start with a real problem. Imagine you've built a model that predicts house prices, and it's guessing for five houses at once. Some guesses will be a bit off, some way off. What we want is one single number that says how wrong the model is overall. Why one number? Because then we can nudge each weight and watch whether that number goes up or down.
