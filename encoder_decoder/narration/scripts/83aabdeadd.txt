# Assign an Integer to Each Email Write that gives each distinct user an integer ID: 1 for the first user seen, 2 for the second new user, and so on. Users repeat in the data — they must keep the same ID. [code block]
# ---
Here's a puzzle: computers love numbers, but our data is full of email addresses. So how do we turn each email into a number? Your job is to give every new user the next integer, starting at one, while repeat users keep the ID they already got. Think about what you'd need to remember as you go. Give it a try first!
