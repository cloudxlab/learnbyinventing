# Assign an Integer to Each Email Write that gives each distinct user an integer ID: 1 for the first user seen, 2 for the second new user, and so on. Users repeat in the data — they must keep the same ID. [code block]
# ---
Here's a small challenge. Every time a user shows up in the data, they need a number, and the same user always gets the same number. The first person you see is one, the next new person is two, and so on.

Before you code, think about what happens when someone appears a second time. How would you remember who you've already seen? Give it a try yourself, then move on when you're ready.
