# Swap In Place All the algorithms in this chapter rearrange elements inside the same list. The basic move is a swap. Write that exchanges the elements at positions and in place (modify the list, return nothing). [code block]
# ---
Every sorting algorithm we'll build in this chapter has one basic move in common: swapping two elements. So let's start there. Your job is to write a function that exchanges the items at two positions in a list, right inside the list itself. It shouldn't make a new list, and it shouldn't return anything. Think about what could go wrong if you overwrite one spot too early. Give it a try!
