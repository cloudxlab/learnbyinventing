# Swap In Place All the algorithms in this chapter rearrange elements inside the same list. The basic move is a swap. Write that exchanges the elements at positions and in place (modify the list, return nothing). [code block]
# ---
Every sorting algorithm in this chapter works by shuffling things around inside the same list, and the smallest move they all share is the swap. Two positions trade their values, and the list changes right where it sits.

Give it a go yourself. Write a function that swaps two elements in place. Here's a hint to think about: what happens to the first value if you overwrite it too early?
