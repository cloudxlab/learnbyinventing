# Partition 0s and 1s Warm-up from real life. You have records labeled 0 or 1: [code block] Move all the 0-records to the front and all the 1-records to the back — without creating another list , touching each element only a constant number of times (a single O(n) pass with swaps). Here's a warm-up from real life. Imagine you've got a list of records, each one labeled either zero or one, all jumbled together. Your job is to get every zero up front and every one in back, without making a second list. Think about two pointers, one coming from each end. What should each one be looking for? Give it a try before moving on.
