Here's a big idea, and you've already met it in the Recursion chapter. To sort a list, split it in half. Then sort each half, using the very same method. Finally, merge the two sorted halves back together.

Before you write anything, think about the base case. What's the smallest list that's already sorted, with nothing left to do? Work that out first, then try writing the function yourself.
