# ON SCREEN:
# Exercise: write partition_01(lst) that moves all 0-records to the front and 1-records to the back in one pass.
# ---
Here's a warm-up for quicksort. You have records labeled 0 or 1, and you need to move all the zeros to the front and all the ones to the back in a single pass. Use two pointers, one starting from each end. When the left pointer finds a 1 and the right finds a 0, swap them.
