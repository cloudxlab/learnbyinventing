Here's a big idea, and you've already seen it in the Recursion chapter. To sort a list, split it in half, sort each half the very same way, then merge the two sorted halves back together.

Try writing it yourself. Start with the base case: how small can a list get before it's already sorted? Think about that first, and the rest will follow.
