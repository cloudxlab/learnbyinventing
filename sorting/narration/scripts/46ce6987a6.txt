# Is It Sorted? Before sorting anything, you need a way to check whether a list is sorted. Write that returns if every element is less than or equal to the next one. [code block]
# ---
Before we sort anything, let's ask a simpler question: how do you know when a list is already sorted? Your first job is to write a function that checks exactly that. It should return true if every element is less than or equal to the one right after it. Think about which pairs you need to compare, give it a try, and then we'll move on.
