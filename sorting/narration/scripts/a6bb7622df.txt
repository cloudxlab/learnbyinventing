Here's a fun twist: what if sorting didn't need comparisons at all? Your task is to write a function that takes a list of ages and returns a list of counts. Position zero holds how many people are age zero, position one holds how many are age one, and so on. Before you code, think about how you'd tally a small list by hand. Give it a try.
