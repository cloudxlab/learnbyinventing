# Part 5: Sorting Without Comparing A puzzle: You must sort the ages of a billion people . Ages are whole numbers between 0 and 200. Your Part 3 algorithm would need ~30 billion comparisons. Can you sort them with zero comparisons between elements ? Hint: how many different values can an age take?

Here's a fun puzzle. Imagine you've got the ages of a billion people, and you need to sort them. Our best algorithm would need around thirty billion comparisons, which is a lot. But what if you didn't compare anything at all? Think about the hint: how many different values can an age actually take? Give it a try before moving on.
