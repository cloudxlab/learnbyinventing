# Count Occurrences Write that returns a list of length , where is how many times age appears. [code block]
# ---
Here's a fun challenge: imagine you have a billion ages, all between zero and a hundred and twenty. Instead of comparing people to each other, what if you just kept a tally? Your job is to write a function that returns a list where each position holds how many times that age shows up. Before you code, think about how big that list needs to be, and what happens each time you see an age. Give it a try!
