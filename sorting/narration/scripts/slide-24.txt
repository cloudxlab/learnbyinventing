# Rebuild the Sorted List If you know there are three 0s, zero 1s, five 2s, ... you can write down the sorted list directly. Write that returns the sorted list using — no comparisons between elements at all. [code block] Then answer: How many operations for n ages with values up to k? (in terms of n and k) Why can't you use this trick to sort arbitrary floats or strings?
# ---
Here's the trick: if you already know how many people are each age, say three zeros, no ones, five twos, you don't need to compare anything. You just write each value out as many times as it was counted, in order. Give the code a try yourself. Then think about the cost in terms of n and k, and why floats and strings break this idea.
