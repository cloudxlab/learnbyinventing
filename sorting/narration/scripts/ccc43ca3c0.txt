# Exercise: write split_sort(lst) — split in half, sort each half recursively, then merge.
# ---
Here comes the recursive leap. To sort a list, split it in half, sort each half using the same method, then merge the two sorted halves. The base case is a list of zero or one elements, which is already sorted. This might feel like magic, but trace through a small example and you'll see it works beautifully.
