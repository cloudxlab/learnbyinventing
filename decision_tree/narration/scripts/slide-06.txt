# Given a list of labels, compute its impurity: [code block]
# ---
Here's a challenge for you: write a function that takes a list of labels and tells us how mixed up it is. We'll call that number its impurity.

Think back to the marble bags. A bag of all one color is pure, and a half-and-half bag is as mixed as it gets. Your function should capture that idea as a single number.

Take a moment to try it yourself, even a rough first attempt. We'll build on it together.
