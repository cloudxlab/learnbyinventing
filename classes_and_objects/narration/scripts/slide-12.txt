# Node with total and count Write a class : stores the value and the two children. returns this node's plus the totals of its children (skip a child if it is ). returns how many nodes are in this subtree. Notice the recursion: a method calling the same method on its children .
# ---
Here's a tiny tree, just a node holding a value and two children. Can you write a class for it? Then give it a method that adds up this node's value plus the totals of its children, skipping any child that's empty. And a second method that counts how many nodes are in the subtree.

Take a moment and notice the pattern. Each method calls itself on the children. That's recursion, and it's doing the real work here. Give it a try before moving on.
