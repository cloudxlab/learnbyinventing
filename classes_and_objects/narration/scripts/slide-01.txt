# Part 1: From Dict to Class You could describe a customer with a dict: . It works, but the data has no behavior: any code that wants to do something with a customer must live somewhere else.
# ---
Let's start with something you already know how to do. Imagine you want to keep track of a customer, so you store their details in a dictionary. It works fine for holding information. But notice what's missing: the data just sits there, and any code that wants to do something with it has to live somewhere else. So what if the data and its actions could travel together? That's the question we're going to explore.
