You just built your own save and load with JSON. Python also has a built-in module called pickle that can save almost any object in a single line, with no helper methods needed. So why did we bother? Well, pickle files only work in Python, humans can't read them, and loading one from a stranger can be unsafe. Your JSON file has none of those problems. Real machine learning tools make the same trade-off: scikit-learn models are shipped as pickles, but configuration files usually travel as JSON or YAML.
