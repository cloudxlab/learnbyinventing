Think about what happens when your program finishes running. The tree you built is gone, and next time you'd have to build it all over again. A model you can't save is a model you have to retrain. So let's fix that. JSON can store simple things like dictionaries, lists, numbers, strings, and booleans, but it has no idea what your objects are. So here's our plan: turn the object into a dictionary, write that to a file, and then rebuild the object when we read it back.
