# Node with total and count Write a class : stores the value and the two children. returns this node's plus the totals of its children (skip a child if it is ). returns how many nodes are in this subtree. Notice the recursion: a method calling the same method on its children .
# ---
Now let's build something a bit different: a tree where every node knows about its children. Your job is to write a Node class that stores a value and two children, then add two methods. One adds up this node's value plus everything below it. The other counts how many nodes are in the subtree. Here's the trick to notice: each method calls itself on the children. Give it a try before moving on!
