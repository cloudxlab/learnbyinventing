Time to build your very first class. Think of a customer at a shop: they have a name and an email, and we want one tidy object that carries both of those around together.

Your job is to write a class called Customer. When you create one, it should store those two values on the object itself. The hint is about using the special setup method, and assigning each value to the object through self.

Then add one small method that gives back a piece of that stored information.

Pause here and give it a go. Don't worry if it feels strange at first. Open the hints only if you get stuck.
