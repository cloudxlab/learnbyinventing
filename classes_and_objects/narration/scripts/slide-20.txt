You just saved your model to a JSON file and loaded it back. Here's a quick aside. Python has a built-in module called pickle that can save almost any object in a single line, with no extra conversion code needed. So why did we bother doing it by hand?

Well, a pickle file only works in Python. People can't read it. And loading one from a source you don't trust can be unsafe. Your JSON file has none of those problems. Real machine learning tools make the same trade-off, and you'll see it everywhere.
