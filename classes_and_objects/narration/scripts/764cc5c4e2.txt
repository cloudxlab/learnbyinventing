Here's what just happened. When you wrote the line that builds an object, Python quietly made an empty object for you. Then it called your init method and handed it that new object. Notice that the object slides in as self. That's the whole trick.

Try calling it yourself and see how it behaves. Each object you make carries its own data, so one class can produce many objects.
