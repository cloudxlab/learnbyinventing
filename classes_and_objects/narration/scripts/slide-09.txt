# ON SCREEN:
# Part 3: Inheritance — Classes That Extend Classes All animals eat; only dogs bark. Instead of repeating in every animal class, write it once and inherit it.
# ---
Think about how many animal classes you'd need to write: a Dog, a Cat, a Bird. Every one of them eats. Do you really want to copy that code into each? Of course not. In this part, we'll write the shared behavior once and let other classes inherit it. Only the dog gets to bark.
