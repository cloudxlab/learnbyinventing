# Part 3: Inheritance — Classes That Extend Classes All animals eat; only dogs bark. Instead of repeating in every animal class, write it once and inherit it.

Welcome to Part 3, where we meet inheritance. Think about animals for a second. They all eat, but only dogs bark. So would you really copy the eating code into every single animal class? That gets messy fast. What if you wrote it once, and let other classes inherit it? Let's see how we'd invent that.
