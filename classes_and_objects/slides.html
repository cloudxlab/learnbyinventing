Part 1: From Dict to Class

Challenge (skip ahead if you can):

Write a class Customer whose constructor takes name and place. Add a method describe() that returns "<name> from <place>".

Already got it? Skip to Part 2.

You could describe a customer with a dictionary:

customer = {"name": "Sandeep", "place": "India"}

It works, but the data has no behavior. Any code that wants to do something with a customer must live somewhere else.

What if the data and the functions that work on it lived together in one package?

That’s a class. It bundles data (attributes) and behavior (methods) into one object.

Write a class Customer. When you call Customer("Sandeep", "India"), Python creates an empty object and runs __init__(self, name, place) on it. Store the arguments as self.name and self.place.

class Customer:
    def __init__(self, name, place):
        self.name = name
        self.place = place

    def describe(self):
        return self.name + " from " + self.place

c = Customer("Sandeep", "India")
print(c.describe())  # "Sandeep from India"
c2 = Customer("Alice", "UK")
print(c2.describe())  # "Alice from UK"

Hint: self.name = name inside __init__. Then describe can use self.name.

What just happened?

  • Customer("Sandeep", "India") constructs an object: Python calls __init__ with it as self.
  • c.describe() is exactly Customer.describe(c) — the object slides in as self. Try it!
  • c and c2 each carry their own name and place. One class, many objects.

Part 2: A Model Is an Object

Challenge (skip ahead if you can):

Write a class TwoPointLine with fit(x, y) (learns slope and intercept from two points) and predict(xs) (uses them to make predictions). Add a ValueError if the user passes more or fewer than two points.

Got it? Skip to Part 3.

A thermometer reads current 1 → 30°, current 2 → 35°. What temperature does current 3 correspond to?

Two points define a line: y = m*x + c. If the object learns m and c once (the fit step), it can answer any future question (the predict step).

Before coding: given points (x1, y1) and (x2, y2), how do you compute slope m and intercept c?

$m = \frac{y_2 - y_1}{x_2 - x_1}$, then $c = y_1 - m \cdot x_1$.

class TwoPointLine:
    def fit(self, x, y):

Quick Check: Dog inherits from Animal. What is the main benefit?

A. Dogs run faster in Python than standalone classes

B. Shared behavior (eat) is written once; each subclass only adds what is different

C. Python requires all classes to inherit from something

D. It prevents you from creating Animal objects directly

Answer: B. Write shared code once in the parent. Children get it for free and only add their own unique behavior.

class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

    def total(self):
        s = self.val
        if self.left:  s += self.left.total()
        if self.right: s += self.right.total()
        return s

    def count(self):
        c = 1
        if self.left:  c += self.left.count()
        if self.right: c += self.right.count()
        return c

def find(self, x):
    if self.val == x:
        return True
    if self.left and self.left.find(x):
        return True
    if self.right and self.right.find(x):
        return True
    return False

def max_depth(self):
    left_d = self.left.max_depth() if self.left else 0
    right_d = self.right.max_depth() if self.right else 0
    return 1 + max(left_d, right_d)

def apply(self, func):
    self.val = func(self.val)
    if self.left:  self.left.apply(func)
    if self.right: self.right.apply(func)

Hint: for max_depth, treat a missing child as depth 0. A leaf returns 1 + max(0, 0) = 1.

Part 5: A Decision Tree Is an Object

Challenge (skip ahead if you can):

Write DecisionNode, Yes, and No classes. Build a job-offer decision tree and test it with .answer({"salary": 2, "learning": 0.5, "distance": 3}).

Got it? Skip to Part 6.

You get a job offer. Your rules:

  1. If salary score < 1 → No
  2. Otherwise, if learning opportunity < 1 → No
  3. Otherwise, if distance < 1 → Yes; too far → No

That’s a tree of decisions. Each node checks one criterion and delegates to a child. Leaves give the final answer.

How do you represent the leaves? They don’t check anything — they just return True or False.

class DecisionNode:
    def __init__(self, criteria, boundary, left, right):
        self.criteria = criteria
        self.boundary = boundary
        self.left = left
        self.right = right

    def answer(self, circumstance):
        if circumstance[self.criteria] < self.boundary:
            return self.left.answer(circumstance)
        return self.right.answer(circumstance)

class Yes(DecisionNode):
    def __init__(self): pass
    def answer(self, circumstance): return True

class No(DecisionNode):
    def __init__(self): pass
    def answer(self, circumstance): return False

Hint 1: answer looks up circumstance[self.criteria]. If < boundary, ask left child; otherwise ask right.

Hint 2: Yes.answer always returns True; No.answer always returns False.

def to_dict(node):
    if isinstance(node, Yes):
        return {"leaf": True}
    if isinstance(node, No):
        return {"leaf": False}
    return {

        "boundary": node.boundary,

Aside — pickle: Python’s pickle can serialize any object in one line. So why bother with JSON?

  • Pickle is Python-only, unreadable by humans, and unsafe to load from untrusted sources
  • JSON is language-agnostic, human-readable, and safe

Real ML tools make the same trade-off: scikit-learn models ship as pickles (via joblib), while model configs travel as JSON or YAML.

Part 7: Bonus — FitPlane

TwoPointLine fits a line through 2 points. In 3D, three points determine a plane $z = ax + by + d$. Finding $a$, $b$, $d$ means solving three linear equations:

x1*a + y1*b + 1*d = z1
x2*a + y2*b + 1*d = z2
x3*a + y3*b + 1*d = z3

class FitPlane:
    def fit(self, points):
        equations = []
        for x, y, z in points:
            equations.append([x, y, 1, z])
        a, b, d = solve_equations(equations)
        self.a = a
        self.b = b
        self.d = d
        return self

    def predict(self, points):
        return [self.a * x + self.b * y + self.d
                for x, y in points]

plane = FitPlane()
plane.fit([(0,0,1), (1,0,2), (0,1,3)])
print(plane.predict([(1,1)]))  # [4.0]

Hint: each point (x, y, z) gives one equation: [x, y, 1, z].
