There are two ways to get set up, and you only need to pick one. Path A is Google Colab. There's nothing to install, because everything runs in your browser, but you'll need an internet connection the whole time. Path B is VS Code. It takes a bit of setup, but then it runs as fast as your own computer, and it works offline. If you just want to start right now, go with Colab. You can always switch later.
