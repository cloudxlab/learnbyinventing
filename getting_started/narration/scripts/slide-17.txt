# Your First Variable In a new cell: [code block] Replace with your actual name. Run it, then change the name and run again.
# ---
Time to write some code of your own! Open a new cell and type a line that gives a variable your name, something like name equals, then your name in quotes. Swap in your real one, then run it. Nothing flashy will happen, and that's fine. Now change the name to someone else's and run it again. Notice how the variable simply holds whatever you last gave it.
