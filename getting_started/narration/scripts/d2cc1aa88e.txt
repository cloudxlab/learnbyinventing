# Create a Notebook. In VS Code, open the Command Palette, type Jupyter: Create New Blank Notebook. VS Code may ask you to select a kernel - that just means which Python should run your code.
# ---
Now let's create a notebook inside VS Code. Press Control Shift P on Windows, or Command Shift P on Mac, to open the Command Palette. Type Jupyter Create New Blank Notebook and select it. If VS Code asks you to select a kernel, don't worry. A kernel just means which version of Python should run your code. Pick the Python version you installed and you're all set. Type the print statement from the slide in the first cell and press Shift Enter to run it.
