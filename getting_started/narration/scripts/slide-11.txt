# ON SCREEN:
# Step 1: Install Python Go to python.org/downloads Click the big "Download Python 3.x.x" button Run the installer Important (Windows): Check the box that says "Add Python to PATH" before clicking Install. If you miss this, Python won't be found from the terminal. Mac: Python 3 may already be installed. Open Terminal and type to check. If not, the python.org installer works, or use if you have Homebrew. Step 2: Install VS Code Go to code.visualstudio.com Download and install for your operating system Step 3: Install Extensions Open VS Code Click the Extensions icon in the left sidebar (or press Ctrl+Shift+X / Cmd+Shift+X ) Search for and install: Python (by Microsoft) — Python language support Jupyter (by Microsoft) — notebook support inside VS Code
# ---
Let's get your tools set up. It's three quick steps: Python, then VS Code, then two extensions.

For Python, grab the installer from python.org. If you're on Windows, tick the "Add Python to PATH" box before you install. It's easy to miss, and without it your terminal won't find Python. Mac users might already have it.

Then VS Code, and finally the Python and Jupyter extensions. Take your time with each one.
