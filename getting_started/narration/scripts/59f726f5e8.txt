# ON SCREEN:
# Quick Reference table. Run a cell: Shift+Enter. Add a new cell: + Code or B. Print something: print("Hello"). Store a value: x = 42. Arithmetic operators: +, -, *, /, **. Text strings in quotes. Read errors: look at the last line.
# ---
Here's your quick reference card. Keep this in mind as you move through the book. Shift Enter runs a cell. The plus Code button adds a new one. Print shows output. The equals sign stores a value. Plus, minus, star, slash, and double star do arithmetic. Text goes in quotes. And when you see an error, the last line tells you what went wrong.
