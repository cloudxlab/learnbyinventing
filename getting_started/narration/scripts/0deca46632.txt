# ON SCREEN:
# Step 1: Install Python. Go to python.org/downloads. Download Python 3. Run the installer. Important Windows: Check "Add Python to PATH". Mac: Python 3 may already be installed. Step 2: Install VS Code. Step 3: Install Extensions.
# ---
There are three steps here. First, install Python from python.org. On Windows, make sure to check the box that says Add Python to PATH. PATH is just a list of folders your computer searches when you type a command. Without it, your computer won't find Python. On Mac, you might already have Python 3. Check by typing python3 dash dash version in the Terminal. Next, install VS Code from code.visualstudio.com. Then open VS Code, go to Extensions, and install the Python and Jupyter extensions by Microsoft.
