# ON SCREEN:
# So far, your functions had one input . But what if a function takes two ?
# [Fragment 1]: The trick: differentiate with respect to one input at a time , treating the other as a constant. This is called a partial derivative .
# ---
Here's the trick: pick just one input to differentiate with respect to, and treat the other one as if it were a fixed number. Everything else works the same way you've already learned. We call this a partial derivative, because you're only looking at part of the function at a time.
