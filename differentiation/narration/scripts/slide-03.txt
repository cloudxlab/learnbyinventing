# Think of a function as a machine . You feed it an input [math], and it gives you an output [math].

Let's start with a picture that'll make everything easier: think of a function as a machine. You drop an input in one side, the machine does its thing, and an output comes out the other. Same input, same output, every time. If you've written a Python function, you already know this idea. Take a second and picture it.
