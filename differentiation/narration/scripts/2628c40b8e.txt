# Your works for two inputs. But what if a function takes 3, 10, or 1000 inputs?
# ---
So far you've worked with functions that take two inputs, and you've found a way to measure how the output changes when each one moves. That's a great start. But real functions are rarely that small. A model might have three inputs, ten, or even a thousand. Before we move on, think about it. Could the same idea still work?
