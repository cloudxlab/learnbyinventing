# Two vectors can point in the same direction but have different lengths. Suppose we only care about direction and want to strip away magnitude.
# [Fragment 0]: Divide every element by the vector s length. The result has length 1 a unit vector . [math]
# ---
Here's the move: divide every element by the vector's length. You'll end up with a vector of length exactly one, a unit vector. It points the same way as before, but the size is gone, so only the direction is left.
