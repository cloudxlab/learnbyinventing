Here's a neat connection. You already know how to measure the distance between two points. Well, the length of a vector is that very same idea, just measured from the origin. So before writing anything new, think about which function you've already built that you can reuse.

Once you have length, a unit vector is simple: same direction, but length one. Try both yourself, then run the check at the bottom.
