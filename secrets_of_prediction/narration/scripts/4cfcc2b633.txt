# In machine learning, a dataset is a matrix. Each row is one sample; each column is one feature. [code block]
# [Fragment 0]: A model s job is to learn a weight vector one number per feature that predicts the output. [code block]

Here's where it gets exciting: a model's whole job is to learn a weight vector, one number for each feature, that turns those columns into a prediction. Think of the weights as dials, and learning is just finding the right setting for each one.
