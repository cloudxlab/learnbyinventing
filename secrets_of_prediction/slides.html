Part 1: What Is a Vector?

You already use vectors every day — you just don’t call them that.

A shopping list is a vector:

shopping = [3, 2, 1]   # 3 apples, 2 bananas, 1 milk

A position on a map is a vector:

cafe = [4, 7]          # 4 blocks east, 7 blocks north

A student’s scores across subjects is a vector:

scores = [85, 92, 78]  # math, science, english

A vector is just a list of numbers where the position of each number means something.

What happens when you go shopping on Monday and Tuesday?

monday  = [3, 2, 1]   # 3 apples, 2 bananas, 1 milk
tuesday = [1, 0, 2]   # 1 apple,  0 bananas, 2 milks

Your total is [4, 2, 3] — add each position separately. That’s vector addition.

What if you’re cooking for a dinner party and need 3 times the recipe?

recipe  = [2, 1, 4]   # 2 eggs, 1 onion, 4 tomatoes
triple  = [6, 3, 12]  # multiply every element by 3

That’s scalar multiplication.

You walk east 3 blocks, then north 4 blocks. Your position is the vector [3, 4].

Now your friend starts at [1, 1] and walks [2, 3]. Where do they end up?

start      = [1, 1]
walk       = [2, 3]
end_up_at  = add_vectors(start, walk)   # [3, 4]

Vector addition = chaining movements. Scaling = going farther in the same direction.

Subtraction works too: add_vectors(a, scale_vector(b, -1)) gives the difference — the direction from b to a.

Quick Check: If v = [5, 0] and w = [0, 3], what is add_vectors(v, w)?

A. [5, 3]    B. [15, 0]    C. [0, 15]    D. [8, 8]

Answer: A. Add position by position: $5+0=5$, $0+3=3$. The two perpendicular walks combine into the diagonal [5, 3].

Part 2: Measuring Vectors

You walked east 3, north 4. How far are you from where you started?

Pythagoras: $\sqrt{3^2 + 4^2} = \sqrt{25} = 5$.

That’s the length (or magnitude) of the vector [3, 4]. For any number of dimensions: $\|v\| = \sqrt{v_1^2 + v_2^2 + \ldots + v_n^2}$.

import math

def vector_length(v):
    return math.sqrt(sum(x ** 2 for x in v))

print(vector_length([3, 4]))      # 5.0
print(vector_length([1, 2, 2]))   # 3.0

Hint: square each element, sum them, take the square root.

Two vectors can point in the same direction but have different lengths. Suppose we only care about direction and want to strip away magnitude.

Divide every element by the vector’s length. The result has length 1 — a unit vector.

$\hat{v} = \frac{v}{\|v\|}$

Example: [3, 4] has length 5, so its unit vector is [0.6, 0.8]. Check: $\sqrt{0.6^2 + 0.8^2} = 1.0$.

print(convert_to_unit([3, 4]))                   # [0.6, 0.8]

Now the big one: how do we measure whether two vectors point in similar directions?

Multiply matching elements and add up: $a \cdot b = a_1 b_1 + a_2 b_2 + \ldots$

This is called the dot product. It tells you how much one vector “goes along” the other.

Same directionLarge positive
Perpendicular (90°)Zero
Opposite directionLarge negative

The dot product is affected by vector lengths. A vector twice as long gives a dot product twice as big, even if the direction is the same.

To measure direction only, take the dot product of the unit vectors. This gives a number between $-1$ and $1$ called cosine similarity:

  • $1.0$ → same direction
  • $0.0$ → perpendicular
  • $-1.0$ → opposite

Real-world use: Two friends rate five movies on a 1–5 scale:

alice = [5, 4, 1, 2, 5]   # loves action, hates romance
bob   = [4, 5, 2, 1, 4]   # similar taste to Alice
carol = [1, 2, 5, 4, 1]   # opposite taste

print(cosine_similarity(alice, bob))    # ≈ 0.97  (very similar)
print(cosine_similarity(alice, carol))  # ≈ 0.32  (quite different)

Ratings are vectors. Cosine similarity tells you how aligned two people’s tastes are — regardless of whether one person rates everything higher than the other.

Quick Check: cosine_similarity([3, 0], [0, 5]) returns 0.0. Why?

A. One of the vectors is zero    B. The vectors are perpendicular — knowing one tells you nothing about the other    C. They have different lengths    D. Cosine similarity only works for unit vectors

Answer: B. [3, 0] points purely east; [0, 5] points purely north. They’re at 90°, so the cosine is zero. Length doesn’t matter.

Part 3: What Is a Matrix?

A matrix is a grid of numbers arranged in rows and columns. In Python, it’s a list of lists:

M = [[1, 2],
     [3, 4]]   # 2 rows, 2 columns

But what does a matrix do?

Think of it as a machine: you feed in a vector, it spits out a new vector. Each row of the matrix computes one element of the output by taking a dot product with the input.

Different matrices do different things to points. Let’s experiment. Apply these matrices to the point [1, 0]:

point = [1, 0]

print(mat_vec_mul([[1,0],[0,-1]], point))   # [1, 0]  → ?
print(mat_vec_mul([[0,-1],[1,0]], point))   # [1, 0]  → ?

Matrices are transformations: flips, rotations, stretches, skews — all encoded in a grid of numbers.

When you apply one transformation and then another, you can combine them into a single matrix. That’s matrix multiplication.

In the product $C = A \times B$, each entry $C[i][j]$ is the dot product of row $i$ of $A$ with column $j$ of $B$.

To get column $j$ of $B$: pick the $j$-th element from every row.

def matrix_mul(A, B):
    n_cols_B = len(B[0])
    result = []
    for row_a in A:
        new_row = []
        for j in range(n_cols_B):
            col_b = [B[r][j] for r in range(len(B))]
            new_row.append(dot_product(row_a, col_b))
        result.append(new_row)
    return result

print(matrix_mul([[1,2],[3,4]], [[5,6],[7,8]]))
# [[19, 22], [43, 50]]

Hint: for each row of $A$ and each column of $B$, take their dot product. Extract column $j$ as [B[r][j] for r in range(len(B))].

Quick Check: You flip a point vertically, then rotate it 90°. Can you do both in one step?

Answer: B. matrix_mul(rotate, flip) gives you one matrix that does both transformations at once. This is why matrix multiplication exists — it chains transformations.

Part 4: Matrices in Action

The matrix that rotates a point counter-clockwise by angle $\theta$ is:

$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$

    # rotation_matrix(90)
    #   → [[≈0, -1], [1, ≈0]]
    # YOUR CODE HERE
    pass

R = rotation_matrix(90)
print(R)
print(mat_vec_mul(R, [1, 0]))  # should be [0, 1]
def rotation_matrix(angle_degrees):
    theta = math.radians(angle_degrees)
    c, s = math.cos(theta), math.sin(theta)
    return [[c, -s],
            [s,  c]]

R = rotation_matrix(90)
print(R)                        # [[≈0, -1], [1, ≈0]]
print(mat_vec_mul(R, [1, 0]))   # [≈0, 1] — rotated 90°!

Hint: convert degrees to radians with math.radians, then use math.cos and math.sin.

A random matrix stretches, skews, and possibly flips the shape. Only rotation matrices keep everything rigid.

There’s one special matrix that does nothing at all:

I = [[1, 0],
     [0, 1]]   # the identity matrix
print(mat_vec_mul(I, [7, 3]))             # [7, 3] — unchanged
print(matrix_mul(I, [[5, 6], [7, 8]]))    # [[5,6],[7,8]] — unchanged

The identity matrix is like multiplying by 1 — it’s the “do nothing” transformation. Every vector passes through unchanged.

Try it: matrix_mul(rotation_matrix(45), rotation_matrix(-45)). You get back the identity — rotating 45° then −45° cancels out.

Quick Check: You multiply a 3×2 matrix by a 2×4 matrix. What size is the result?

A. 3×4    B. 2×2    C. 4×3    D. Can’t multiply — sizes don’t match

Answer: A. An $(m \times k)$ matrix times a $(k \times n)$ matrix gives an $(m \times n)$ result. The inner dimensions must match (both are 2 here); the outer dimensions form the result shape: $3 \times 4$.

Part 5: Why This Matters for ML

In machine learning, a dataset is a matrix. Each row is one sample; each column is one feature.

# 3 houses: [bedrooms, sq_feet, age_years]
houses = [[3, 1500, 10],
          [2, 1200, 25],
          [4, 2000,  5]]

A model’s job is to learn a weight vector — one number per feature — that predicts the output.

weights = [50, 0.1, -2]   # price per bedroom, per sq_ft, per year

Prediction for one house = dot_product(features, weights).

Predict the price of each house using the weight vector:

houses  = [[3, 1500, 10], [2, 1200, 25], [4, 2000, 5]]
weights = [50, 0.1, -2]

def predict_one(features, weights):
    return dot_product(features, weights)

for house in houses:
    print(predict_one(house, weights))
# 280.0  (3*50 + 1500*0.1 + 10*-2)
# 170.0  (2*50 + 1200*0.1 + 25*-2)
# 390.0  (4*50 + 2000*0.1 + 5*-2)

Hint: you already wrote the function that does this — dot_product!

Predicting one sample at a time works, but there’s a faster way. If the dataset is a matrix and the weights are a vector…

mat_vec_mul(houses, weights) predicts all houses at once!

print(mat_vec_mul(houses, weights))
# [280.0, 170.0, 390.0] — same answers, one call

This is why ML libraries use matrices everywhere. With numpy, X @ w computes thousands of predictions in one operation, orders of magnitude faster than a Python loop.

Matrix multiplication = running all predictions for all models in a single operation.

Quick Check: In the expression predictions = X @ w, what are X and w?

A. X is the weights, w is the data    B. X is the data matrix (samples × features), w is the weight vector    C. Both are weight vectors    D. X is a single sample, w is all samples

Answer: B. Each row of $X$ is one sample’s features. The dot product of each row with $w$ gives that sample’s prediction. Matrix-vector multiply does all rows at once.
