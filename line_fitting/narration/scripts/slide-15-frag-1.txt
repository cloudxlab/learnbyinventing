# For line y = 3x 1, the error at each point is the difference between actual and predicted: x Actual Predicted Error 1 2 2 0 2 5 5 0 3 7 8 1 How do we combine these into a single number?
# [Fragment 1]: (0&sup2; + 0&sup2; + ( 1)&sup2;) / 3 = 0.33 This is the Mean Squared Error (MSE) .
# ---
Add up the squared errors and divide by how many points there are, and you get a single number: about a third. That's the Mean Squared Error. Squaring keeps misses from cancelling each other out, and it makes bigger misses count for more.
