# For line y = 3x 1, the error at each point is the difference between actual and predicted: x Actual Predicted Error 1 2 2 0 2 5 5 0 3 7 8 1 How do we combine these into a single number?
# [Fragment 1]: (0&sup2; + 0&sup2; + ( 1)&sup2;) / 3 = 0.33 This is the Mean Squared Error (MSE) .
# ---
Add up the squared errors, then divide by how many points there are, and you get one number that sums up how wrong the line is. Here it's about a third, which is small, so this line fits pretty well. This is the Mean Squared Error, and it's the score we'll use to compare lines.
