# For line y = 3x 1, the error at each point is the difference between actual and predicted: x Actual Predicted Error 1 2 2 0 2 5 5 0 3 7 8 1 How do we combine these into a single number?
# ---
Here's a thought: we've got a line, and we've got an error at every single point. Some are zero, but one of them is off by one. Now we have a bunch of numbers, and we want just one number that tells us how good this line is overall. Before we move on, try this yourself. How would you squash those errors into a single score? Think about what could go wrong if you just added them up.
