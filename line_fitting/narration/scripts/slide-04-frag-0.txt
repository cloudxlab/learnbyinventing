# Let's look back and embrace what we have done. We had data (two points) and we came up with a model (a line), and with this model we are able to answer unseen questions. Our Line Model Training Inference
# [Fragment 0]: In machine learning, coming up with the model is called training and using the model to give output is called inference .
# ---
Here's the vocabulary you'll hear everywhere in machine learning. Coming up with the model, like finding our line from two points, is called training. Then using that model to answer a brand-new question is called inference.
