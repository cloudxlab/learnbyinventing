# The step function The bluntest squasher possible: returns if , else . Write it. (In 1958 this exact function, wrapped around a weighted sum, was called the perceptron — the first artificial neuron.) Your task: Implement .
# ---
Time to build your very first artificial neuron. We'll start with the bluntest squashing function there is, the step function. It asks one simple question: is the input at or above zero? If yes, it says one. If not, it says zero. That's all! Back in 1958, this exact idea wrapped around a weighted sum was called the perceptron, the first artificial neuron. Give writing it a try yourself.
