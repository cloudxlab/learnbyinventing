Here's the simplest squasher you can imagine: if the input is zero or positive, output one. Otherwise, output zero. That's it. Your task is to write this as a function called step_function.

Fun fact: back in 1958, this exact idea — a step function wrapped around a weighted sum — was called the perceptron. It was the very first artificial neuron. So you're about to build the oldest piece of neural network history. Give it a try, and use the hints if you need a nudge.
