Look at the tax rule one more time: zero below a threshold, then a straight ramp above it. There's an activation function that IS exactly that shape. Before looking at any formula, write a function that outputs zero for negative inputs and the input itself for positive inputs. That's ReLU.

Now swap sigmoid for ReLU in your two-neuron model and train again. This time, the fit should be near-perfect — because the network can represent the true tax rule exactly. And here's the big reveal: ReLU, the rectified linear unit, is the default activation function of modern deep learning. It powers nearly every large model out there. Sigmoid saturates at both ends, but ReLU never saturates on the positive side.
