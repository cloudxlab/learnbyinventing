Part 1: Pulling Numbers Apart

Challenge (skip ahead if you can):

Write two Python functions: last_digit(n) that returns the last digit of a number, and remove_last_digit(n) that chops the last digit off. Then verify that remove_last_digit(n) * 10 + last_digit(n) == n for any n.

Already got it? Skip to Part 2.

Take the number 2784. How is it built?

2784 = 2×1000 + 7×100 + 8×10 + 4×1

Every digit has a place value. The last digit is 4 (the ones place).

Python has two operators perfect for pulling numbers apart:

  • % — modulo: gives the remainder after division
  • // — integer division: divides and throws away the remainder

Before coding — answer in your head:

  1. What is 2784 % 10?
  2. What is 2784 // 10?
  3. Which one gives you the last digit?
  4. Which one gives you the number with the last digit chopped off?
  • 2784 % 10 = 4 — the remainder is the last digit!
  • 2784 // 10 = 278 — integer division chops the last digit off!

Verify this holds for other numbers: 50 % 10? 7 % 10? 100 % 10?

When you deposit money, it earns interest. The formula is:

$\text{Interest} = \dfrac{\text{Principal} \times \text{Rate} \times \text{Time}}{100}$

$\frac{1000 \times 5 \times 2}{100} = 100$

A point on a flat plane is an (x, y) pair. How far apart are (0, 0) and (3, 4)?

Before coding:

These form the two legs of a right triangle. And you already know how to find the hypotenuse!

Part 4: Modeling a Line

A straight line can be written as:

$y = mx + c$

  • c — the intercept (where the line crosses the y-axis)

$y = 2 \times 4 + 3 = 11$

Now the reverse: given two points, find the line through them.

Before coding: given $(1, 3)$ and $(3, 7)$, find $m$ and $c$ by hand.

Slope: $m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{7 - 3}{3 - 1} = 2$

Intercept: $c = y_1 - m \cdot x_1 = 3 - 2 \times 1 = 1$

So the line is $y = 2x + 1$. Check: $2 \times 3 + 1 = 7$  ✓

def fit(x1, y1, x2, y2):
    m = (y2 - y1) / (x2 - x1)
    c = y1 - m * x1
    return (m, c)

print(fit(1, 3, 3, 7))    # (2.0, 1.0)
print(fit(0, 5, 10, 25))  # (2.0, 5.0)

Hint 1: slope is rise over run: (y2-y1) / (x2-x1).

Hint 2: intercept is y1 - m * x1.

This is the essence of linear regression — fit a line to data, then use it to predict new values.

Part 5: How Fast Is a Function Changing?

Challenge (skip ahead if you can):

Write approx_derivative(f, x) that takes any function $f$ and a point $x$, and returns the rate at which $f$ is changing at $x$.

def g(x): return x ** 2
print(approx_derivative(g, 3))  # ≈ 6

Got it? Skip to Part 6.

Imagine a car’s position at time $t$ is given by $f(t) = t^2$.

  • At $t = 2$: position = $4$
  • At $t = 3$: position = $9$

How fast was the car going between $t = 2$ and $t = 3$?

$\text{speed} = \frac{\text{change in position}}{\text{change in time}} = \frac{9 - 4}{3 - 2} = 5$

But that’s the average speed over a whole second. How fast was it going exactly at $t = 2$?

Shrink the time interval! Instead of $t = 2$ to $t = 3$, try $t = 2$ to $t = 2.001$:

  • $f(2) = 4$
  • $f(2.001) = 4.004001$
  • Speed $\approx \frac{4.004001 - 4}{0.001} = 4.001$

Even smaller — $t = 2$ to $t = 2.00001$:

  • Speed $\approx \frac{f(2.00001) - f(2)}{0.00001} \approx 4.00001$

It’s converging to 4.0! The instantaneous speed at $t = 2$ is 4.

This is called the derivative: how fast a function is changing at a single point.

The power of approx_derivative: it works on any function!

print(approx_derivative(sine, 0))    # ≈ 1.0  (cos(0) = 1)

You didn’t need to know any calculus rules. You just measured how much the output changes for a tiny change in input.

This numerical derivative is exactly how gradient descent works in machine learning!
