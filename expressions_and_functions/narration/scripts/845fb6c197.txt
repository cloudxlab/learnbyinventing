Let's start taking numbers apart. Any number is built from place values, like hundreds, tens, and ones. Python gives you two handy operators for pulling those pieces out: one gives the remainder of a division, and the other throws the remainder away.

Before you run anything, predict what each one gives. Which one grabs the last digit? Which one chops it off? And will that still hold for single-digit numbers and for zero? Reason it out first, then test yourself.
