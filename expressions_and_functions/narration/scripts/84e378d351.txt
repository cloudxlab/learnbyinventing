# Distance Metric Intuition A delivery drone flies in a straight line from point A to point B, but a delivery truck must follow streets laid out in a grid. Which distance formula should you use to estimate each vehicle's travel distance? A. Euclidean for both B. Manhattan for both C. Euclidean for the drone, Manhattan for the truck D. Manhattan for the drone, Euclidean for the truck
# ---
Here's a quick puzzle about distance. Picture a delivery drone and a delivery truck, both heading from point A to point B. The drone can cut straight across the sky. The truck is stuck following streets laid out in a grid.

Before you pick an answer, think about the path each one actually travels. Which formulas did we build earlier, and which one matches each path? Give it a try yourself first.
