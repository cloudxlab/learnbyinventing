Here's everything you invented in this chapter, mapped to its real name. You timed functions and plotted growth curves — that's empirical complexity analysis. You counted operations instead of timing — operation counting. You dropped constants and kept only the growth family — asymptotic analysis. You invented a shorthand for "grows like" — that's Big O notation. You read code to predict growth without running it — static complexity analysis. You explored best, worst, and average cases — worst-case analysis. You counted extra memory — space complexity. And you traded memory for speed — the time-space tradeoff. Every one of these ideas, you built from scratch.
