# One function's time grows proportionally to the input size. The other grows proportionally to the square of the input size. This distinction is enormous. On a million items: The linear function takes ~1 second The quadratic function takes ~ 11 days Understanding which category your algorithm falls into is one of the most important skills in programming.
# ---
This is where the whole idea comes together. You've seen one function whose time grows in step with the input, and another whose time grows with the square of the input. On a million items, that's the difference between about a second and almost eleven days. Same computer, same task. Just a different shape of algorithm. Knowing which side yours falls on is one of the most valuable skills a programmer can have.
