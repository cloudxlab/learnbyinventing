# Part 5: Memory Complexity Time isn't the only resource that matters. Memory (space) does too. The same Big O notation works — instead of asking "how does time grow?" we ask "how much extra memory does this algorithm need as the input grows?"
# ---
We've figured out how fast algorithms grow in time, but time isn't the only thing that costs us. Memory matters too. Every list you build and every copy you make takes up space. The good news is that we can use the same Big O idea here. Now we just ask how much extra memory an algorithm needs as the input grows.
