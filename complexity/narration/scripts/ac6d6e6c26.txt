# ON SCREEN:
# Part 5: Memory Complexity Time isn't the only resource that matters. Memory (space) does too. The same Big O notation works — instead of asking "how does time grow?" we ask "how much extra memory does this algorithm need as the input grows?"
# ---
Time isn't the only thing that costs us something. Memory matters too. Every number or list your program stores takes up space, and computers don't have unlimited amounts of it. The good news is we don't need a new tool. We can use the same Big O idea, but ask a different question: as the input grows, how much extra memory does the algorithm need?
