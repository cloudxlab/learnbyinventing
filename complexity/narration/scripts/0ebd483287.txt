You've now seen the growth families show up in real code, and look how clean the pattern is. Doing one thing no matter the input is constant. Halving the range each step is logarithmic. A single loop is linear. A loop that does a halving's worth of work each time is linearithmic, and a loop inside a loop is quadratic. Take a moment to see how the code shape tells you the growth.
