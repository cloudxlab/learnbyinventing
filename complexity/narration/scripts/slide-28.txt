# ON SCREEN:
# See the Space Grow Create lists of increasing size and n×n matrices of increasing size. Count the number of elements in each to verify the growth pattern. For lists: how does the element count grow with n? For matrices: how does the element count grow with n?
# ---
Here's a chance to check your own thinking. We've got lists growing in size, and now square matrices growing too. Count the elements in each one, and write down what you find. For the lists, what happens to the count as n goes up? For the matrices, is it the same pattern, or does something different happen? Take a moment to try it yourself before moving on.
