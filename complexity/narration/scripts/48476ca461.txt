# ON SCREEN:
# Rules of thumb for reading code: Pattern Big O No loop — fixed number of operations O(1) Single loop over n items O(n) Two separate loops (not nested) O(n) — it's [math], constants drop Loop inside a loop O(n²) Loop that halves the range each step O(log n) Loop over n, each iteration does O(log n) work O(n log n)
# ---
You've now seen how each kind of loop behaves, so here's a handy cheat sheet for reading any code. No loop at all means a fixed amount of work. One loop over your items means work grows in step with n. Two loops side by side still just add up, so the constants drop away. A loop inside a loop is where things get quadratic. Halving the range each time gives you log n. And a loop over n that does log n work inside is n log n. Next time you see code, try matching it to one of these.
