Here are two functions to compare. One adds up every number in a list, using a single loop. The other checks whether any two numbers add up to a target, with a loop inside a loop. We'll give that second one a target of negative one. Since every number is positive, no pair can ever match, so the function has to check every single pair before giving up. That lets us measure its full workload. Before we run anything, take a guess: which one do you think will take longer as the list grows?
