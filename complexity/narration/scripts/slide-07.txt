# Part 2: Counting Steps Timing is noisy — it depends on your computer's speed, what else is running, even the room temperature. Can we predict how an algorithm grows without running it? Yes: count the key operations .
# ---
Timing an algorithm is a bit like weighing yourself on a wobbly scale. The answer changes with your computer's speed, whatever else is running, even small things you'd never think of. So here's a big question: can we predict how an algorithm grows without running it at all? We can. The trick is to count the key operations. Let's see how.
