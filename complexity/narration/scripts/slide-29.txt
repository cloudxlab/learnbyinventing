# See the Space Grow Create lists of increasing size and n×n matrices of increasing size. Count the number of elements in each to verify the growth pattern. For lists: how does the element count grow with n? For matrices: how does the element count grow with n?
# ---
Let's see the space these structures actually take up. Look at the lists first, then the matrices, and count the elements in each one as n gets bigger. Before you peek at the pattern, jot down a guess. When the list doubles in size, what happens to the count? And when the matrix side doubles, what happens? Try it yourself first.
