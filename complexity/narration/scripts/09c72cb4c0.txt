# The time space tradeoff. Two ways to check for duplicates: [code block]
# ---
Here's a design choice you'll run into all the time. There are two ways to check a list for duplicates. One is slow but uses almost no extra memory. The other is fast but needs extra space. Look at both versions and think about what each one is doing. Where do you think the time goes, and where does the memory go?
