# ON SCREEN:
# Quick Check: A function takes n numbers and creates a dictionary mapping each to its square. What is the space complexity? A. O(1) dictionaries are always constant B. O(n) one entry per input element C. O([math]) D. O(log n)
# [Fragment 0]: Answer: B. The dictionary stores n key-value pairs. Extra memory grows proportionally to n.
# ---
Yes, B is right! The dictionary holds one entry for each of the n numbers, so the extra memory we use grows right alongside the input. Double the numbers, double the entries, and that's what linear space looks like.
