# Does the Constant Matter? Write two functions that both loop through a list once, but one does 3× as much work per element. For example, one adds each element once, the other adds it three times. Time both on sizes 10,000, 100,000, and 1,000,000. Compute the ratio of their times for each size. Does the ratio stay constant or change as n grows?

Here's a question that might surprise you: if one function does three times as much work as another, is it really slower in a way that matters? Let's find out. Write two functions that each loop through a list once, but one does triple the work per element. Time both at three different sizes, then compare their ratios. Before you run anything, make a guess about whether that ratio will stay steady or drift as the list grows. Give it a try yourself first.
