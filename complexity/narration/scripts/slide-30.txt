Every algorithm has two price tags: how much time it takes, and how much memory it uses. You now know how to read both. As we move through the chapters ahead, you'll keep running into this tradeoff. Some algorithms are fast because they spend extra memory, while others save memory but take longer. Choosing between them is a real skill, and you've just started building it.
