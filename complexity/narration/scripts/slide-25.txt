# ON SCREEN:
# Rules of thumb for reading code: Pattern Big O No loop — fixed number of operations O(1) Single loop over n items O(n) Two separate loops (not nested) O(n) — it's [math], constants drop Loop inside a loop O(n²) Loop that halves the range each step O(log n) Loop over n, each iteration does O(log n) work O(n log n)
# ---
Here's a handy cheat sheet for reading code and spotting its Big O. You've invented every one of these patterns yourself, so this is just putting them side by side. No loop means a fixed amount of work. One loop over n items is linear. Two loops back to back still add up to linear, because constants drop away. A loop inside a loop gives you n squared. Halving the range each step gives you log n. And a loop over n where each pass does log n work gives n log n. Next time you read code, try matching it to one of these.
