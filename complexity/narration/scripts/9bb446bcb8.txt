Here's a challenge for you. Can you write one function that figures out a function's Big O class all by itself? The idea is to measure how many steps it takes, then double the input size and see how that count changes. Does it barely move, roughly double, or explode? Those patterns should tell you which class you're looking at. If you already see how to do it, go ahead and skip to the end. Otherwise, let's build up to it together.
