# Rules of thumb for reading code: Pattern Big O No loop fixed operations O(1) Single loop over n items O(n) Two separate loops (not nested) O(n) [math] Loop that halves range each step O(log n) Loop of n, each does O(log n) work O(n log n) Loop inside a loop, both over n O([math])
# ---
Here's a handy cheat sheet for reading code. You've just invented most of these patterns yourself, so now we can put them side by side. No loop means a fixed number of steps. One loop over n items is linear. Two loops back to back still add up to linear. A loop that halves its range is logarithmic. A loop where each pass does logarithmic work gives n log n. And a loop inside a loop gives n squared. Next time you see code, try spotting these shapes.
