# Sparse MapReduce Matrix Multiplication Your task: write where each argument is a list of triples of the non-zero entries. Return a dict mapping for the non-zero entries of the product.
# ---
You've built the recommender with dense matrices, but real-world rating data is mostly empty. Almost nobody has rated almost everything. So here's a challenge: multiply two matrices while only touching the entries that actually exist. Each matrix comes in as a list of triples, row, column, value. Think about which pairs of entries can actually combine, then group and add them up. Give it a try yourself first.
