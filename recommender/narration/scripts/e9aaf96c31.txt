The answer is B. A twenty-thousand by twenty-thousand item-item table has about four hundred million entries -- big, but totally manageable. A three-hundred-million by three-hundred-million user-user table would have ninety quadrillion entries, which is impossible to store. Plus, movie taste profiles change slowly, so the item-item table doesn't need constant updating.
