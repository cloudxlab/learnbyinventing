# Quick Check: A brand-new user signs up and hasn t rated any movies. What happens when we try to recommend movies? A. The system recommends the most popular movies B. The similarity vector is all zeros no direction, no meaningful recommendations C. It crashes with a division error D. It works fine using the defaults
# [Fragment 0]: Answer: B. With no ratings, the user s vector is all NaN (filled to mean). Their direction is meaningless. This is the cold-start problem the system can t help until it knows your taste.
# ---
Exactly, it's B. With no ratings, there's no direction to compare, so the system has nothing to go on. This is called the cold-start problem, and it's why so many apps ask what you like the moment you sign up.
