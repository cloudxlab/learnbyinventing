Here's another way to handle negative exponents. This time you won't flip anything at the end. Instead, you'll make the recursion itself climb toward zero. If the exponent is negative, you can raise it by one on each call, so it walks up until it hits the same base case that positive exponents reach by counting down. Write it with one base case and two recursive cases, then run the tests. The big lesson is that a recursion only needs each call to move closer to the base case. Coming from below works just as well as coming from above.
