Time to write your own version. Think about the very smallest case first: what's the first value where the answer is just one simple thing, with nothing left to figure out? That's your base case. Then ask yourself, for any bigger number, how could you build the answer using the same function on something slightly smaller? Grab a pencil, work it out, and then try the code.
