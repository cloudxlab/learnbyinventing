Here's a fun one to think about: multiplying is really just repeated adding. Four times three means adding four to itself three times. Before you code anything, grab a pencil and ask yourself two questions. First, what value for the second number makes the answer obvious, with no adding at all? Second, for any other value, how could you write the answer using a slightly smaller version of the same problem? Give it a real try before moving on.
