# Part 5: Division by Repeated Subtraction
# ---
Welcome to Part 5. So far we've multiplied and raised things to powers by repeating a smaller version of the same job. Now let's try the same trick on division. Think about what division really is when you strip it down. If you only knew how to subtract, how could you figure out how many times one number fits inside another? Give it some thought before we move on.
