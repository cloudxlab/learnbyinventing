Let's try Fibonacci, another function with two recursive calls. Write fib of n using plain recursion, test it on fib of ten, then time fib of thirty and thirty-five. You'll notice something alarming. Then fix it with memoization: a dictionary that caches results so you never compute the same value twice. Hints are there if you want them.
