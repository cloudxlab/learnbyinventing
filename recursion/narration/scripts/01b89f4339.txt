# ON SCREEN:
# Quick Check: What is the role of the base case in a recursive function? A. It makes the function run faster B. It tells Python to use a loop instead C. It provides the stopping condition the simplest case answered directly, without another recursive call D. It handles invalid inputs like negative numbers
# [Fragment 0]: Answer: C. The base case is the stopping condition the simplest input answered directly. Without it, recursion never ends.
# ---
That's right, it's C! The base case is the simplest version of the problem, the one you can answer directly without calling the function again. Without it, the recursion would never stop.
