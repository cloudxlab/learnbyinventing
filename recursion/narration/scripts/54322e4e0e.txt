Second hint for the memoized version. Create an empty dictionary called cache outside the function. At the top of fib, check if n is already in the cache, and if so, return it immediately. Otherwise, compute the answer as before, store it in the cache, and then return it. That small change makes fib of thirty-five nearly instant.
