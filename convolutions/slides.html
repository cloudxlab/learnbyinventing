Part 1: What Is an Image?

Challenge (skip ahead if you can):

Write conv(image, weights) that slides a 3×3 filter over a grayscale image, producing edge maps, blurs, and sharpening — all from the same function.

Already got it? Skip to the end.

To a computer, an image is just a grid of numbers:

from PIL import Image
import numpy as np

color_arr = np.array(Image.open("cat.jpg"))
print(color_arr.shape)   # (360, 480, 3) — height, width, 3 colors
print(color_arr.dtype)   # uint8 — values 0 to 255

Each pixel is three numbers: (Red, Green, Blue).

print(color_arr[0, 0])   # e.g., [143, 98, 72] — top-left pixel
# 143 red, 98 green, 72 blue

A grayscale image is simpler: one number per pixel (0 = black, 255 = white).

gray = np.array(Image.open("cat.jpg").convert("L"))
print(gray.shape)        # (360, 480) — just height × width
print(gray[0, 0])        # e.g., 107 — a medium gray

Quick Check: An image has shape (100, 200, 3). What does this tell you?

Answer: B. Height 100, width 200, with Red, Green, and Blue channels.

A. Green light has the most energy    B. The human eye is most sensitive to green    C. There are more green pixels in most images    D. It’s arbitrary — any weights would work

Part 3: Shrinking — Downsampling

How do you make an image smaller? One idea: skip every other pixel. Write downsample_nearest that halves the size:

Quick Check: A 2×2 block contains pixels [10, 20, 200, 210]. What does average pooling produce?

A. 20 — median of the block    B. 110 — average of the four values    C. 210 — max of the block    D. 10 — min of the block

Answer: B. $(10 + 20 + 200 + 210) / 4 = 110$. Average pooling blends all four pixels into one.

print(big.shape)   # (360, 480) — back to original size
# but it looks "blocky" — each pixel became a 2×2 square

Hint: output pixel (r, c) copies from source pixel (r // 2, c // 2).

Nearest-neighbor upsampling is blocky. We can do better by blending between neighbors. First, the building block — linear interpolation:

def lerp(a, b, t):
    """Blend: t=0 gives a, t=1 gives b, t=0.5 gives midpoint."""
    return a + t * (b - a)

lerp(100, 200, 0.0)   # 100
lerp(100, 200, 0.5)   # 150
lerp(100, 200, 1.0)   # 200

Bilinear interpolation does this in both directions: blend horizontally, then vertically (or vice versa).

For each output pixel, compute which source coordinate it maps to (a fractional position), then blend the four nearest source pixels.

Quick Check: Why does bilinear upsampling produce smoother results than nearest-neighbor?

A. It uses more memory    B. It blends neighboring pixels instead of copying one    C. It makes the image brighter    D. It adds random noise for smoothness

Answer: B. Bilinear interpolation creates gradual transitions by blending four neighbors. Nearest-neighbor just copies one pixel, creating hard edges.

Part 5: The Convolution

The most powerful operation in computer vision is surprisingly simple: slide a small grid of weights over the image, and at each position compute a weighted sum.

Example: a 5×5 image, identity kernel [[0,0,0],[0,1,0],[0,0,0]]:

Image patch:            Weights:         Result:
  10  20  30            0  0  0
  40  50  60      ×     0  1  0     =   50
  70  80  90            0  0  0
# Only the center pixel survives (multiplied by 1)

Now try an averaging kernel [[1,1,1],[1,1,1],[1,1,1]] / 9:

# (10+20+30+40+50+60+70+80+90) / 9 = 50
# Every pixel in the patch contributes equally → blur!

Now try different kernels — same function, different weights, wildly different results:

# Box blur (average neighbors)
blur = np.ones((3, 3)) / 9.0
blurred = conv(gray.astype(float), blur)

# Sharpen (boost center, subtract neighbors)
sharpen = np.array([[0, -1, 0],
                    [-1,  5, -1],
                    [0, -1, 0]], dtype=float)
sharpened = conv(gray.astype(float), sharpen)

The blur smooths out noise. The sharpen makes edges pop. All from the same conv function — only the weights changed!

Edge detection. These two kernels detect edges in different directions:

# Sobel-x: detects vertical edges (brightness change left↔right)
sobel_x = np.array([[-1, 0, 1],
                     [-2, 0, 2],
                     [-1, 0, 1]], dtype=float)

# Sobel-y: detects horizontal edges (brightness change top↔bottom)
sobel_y = np.array([[-1, -2, -1],
                     [ 0,  0,  0],
                     [ 1,  2,  1]], dtype=float)

sx = conv(gray.astype(float), sobel_x)
sy = conv(gray.astype(float), sobel_y)

# Combine both directions into edge magnitude:
edges = np.sqrt(sx**2 + sy**2)

Sobel-x highlights vertical edges; Sobel-y highlights horizontal edges. The combined magnitude shows all edges — the outline of every object in the image.

Quick Check: What does the kernel [[-1,-1,-1],[0,0,0],[1,1,1]] detect?

A. Vertical edges (left–right changes)    B. Horizontal edges (top–bottom changes)    C. Diagonal edges    D. Nothing — it blurs the image

Answer: B. Negative weights on top, positive on bottom. It responds to brightness differences between top and bottom rows — horizontal edges.

The full edge detection pipeline — assemble everything you’ve built:

# 1. Convert to grayscale

# 2. Smooth to reduce noise
blurred = conv_same(gray.astype(float),
                    np.ones((3,3)) / 9.0)

# 3. Detect edges in both directions
sx = conv_same(blurred, sobel_x)
sy = conv_same(blurred, sobel_y)

# 4. Combine into edge magnitude
edges = np.sqrt(sx**2 + sy**2)

# edges is a clean edge map of the original photo —
# bright pixels are edges, dark pixels are flat regions

Four lines of code, all using the same conv function. This is exactly how the first layers of a Convolutional Neural Network (CNN) work — except the network learns the kernel weights from data.
