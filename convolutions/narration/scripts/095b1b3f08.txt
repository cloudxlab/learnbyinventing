# ON SCREEN:
# Exercise 8.1: Write that surrounds an image with zeros. Hint Place inside at offset using slice assignment.
# ---
Time to build your own padding tool. Your job is to write a function that takes an image and surrounds it with a border of zeros. Think about what size the new, bigger canvas needs to be, and where the original image should sit inside it.

Before you write anything, sketch a tiny example on paper. Try a three-by-three image with a one-pixel border. How big is the result, and which positions hold the original pixels?

Give it a real try first. If you get stuck, the hint is there whenever you want it.
