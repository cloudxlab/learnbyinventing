# ON SCREEN:
# Part 5: Growing an Image — Upsampling to 100x100
# ---
Now let's make things bigger. So far we've been shrinking images, but what if you need to go the other way? Imagine taking a tiny picture and stretching it up to one hundred by one hundred pixels. There's a catch: you've got to invent pixels that were never there. How would you fill them in? Give it some thought.
