# Before coding: Your returns a smaller image. A 100 100 image with a 3 3 kernel gives what size?
# [Fragment 0]: 98 98. You lose one pixel on each side because the 3 3 window can t center on the border pixels. General formula: input size [math] with kernel size [math] gives output size [math].

That's 98 by 98. The 3 by 3 window needs a neighbor on every side, so the border pixels can't be centers, and you lose one pixel on each edge. In general, the output shrinks by the kernel size minus one.
