# Nearest-neighbor upsampling is blocky. We can do better by blending between neighbors . First, the building block linear interpolation: [code block]
# [Fragment 0]: Bilinear interpolation does this in both directions: blend horizontally, then vertically (or vice versa). For each output pixel, compute which source coordinate it maps to (a fractional position), then blend the four nearest source pixels.
# ---
Here's the idea: do that same blending twice, once sideways and once up and down. For each output pixel, we work out where it lands in the original image, usually between pixels, and mix the four nearest ones based on how close each is.
