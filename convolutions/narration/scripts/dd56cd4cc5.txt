Here's an exercise to try yourself. We've stretched things in one direction with linear interpolation. Now let's do it in both directions at once, which is called bilinear, to get smooth upsampling.

Start with the pencil-and-paper part. Pick an output pixel and ask where it lands in the source image. That's usually a fractional coordinate, somewhere between pixels. Which four source pixels surround it?

Work that out first. Then blend across the top pair, across the bottom pair, and blend those two results vertically.
