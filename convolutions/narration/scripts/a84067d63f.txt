# Downsampling shrinks. What about making an image bigger ? Simplest idea: repeat each pixel into a 2 2 block.
# ---
We've seen how downsampling shrinks an image. Now let's flip it around: how would you make an image bigger? Think about it for a moment. What's the simplest idea you can come up with? Here's one to start with: take every single pixel and repeat it into a little two-by-two block.
