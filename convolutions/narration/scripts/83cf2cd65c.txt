# ON SCREEN:
# Exercise 3.1: Shrink by picking every other pixel (nearest-neighbor downsampling). Hint Output pixel comes from source pixel .
# ---
Here's a fun one: how would you make a picture smaller? Try shrinking an image by picking just every other pixel. That's called nearest-neighbor downsampling. Before you code, think about it on paper. If the new image is half the size, which pixel in the original should each output pixel copy from? Work out that link between the output position and the source position, then write it yourself.
