So far we've worked with grayscale images, which are just a flat grid of numbers. But real photos are color, with three layers stacked together: red, green, and blue. So how should a convolution handle that? Here's a first idea: run the same kernel on each color channel separately, then stack the results back together. Try writing it yourself, then test it with a couple of kernels. And think about when you'd want a different kernel for each channel.
