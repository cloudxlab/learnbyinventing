Here's a challenge before we write any code. We've got a big hundred-by-hundred image, and we want to shrink it down to fifty-by-fifty. That's four times fewer pixels, so every pixel in the new image has to be built from pixels in the old one. Grab a pencil and think it through. Which input pixels does each output pixel come from? If it covers a little group of four, what single number would you give it? See if you can come up with at least three different choices. And last, do we lose anything when we shrink? Could we ever get the original back perfectly? Jot down your answers, then keep going.
