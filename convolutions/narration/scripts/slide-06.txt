# ON SCREEN:
# Part 2: Extracting a Color Channel
# ---
Now that we can see an image as a grid of numbers, let's try something fun: pulling out just one color. Every pixel has a red, a green, and a blue value stacked together. What if we kept only one of those and threw the rest away? Before you look at any answer, think about how you'd do it with array indexing. Give it a try!
