Part four: shrinking an image. So far we've been sliding a small window across a picture and getting a new picture back. Now let's use that same idea for a different goal: making the picture smaller. Think about it first. If you wanted an image with half the width and half the height, how would you decide which pixels to keep, or how to blend them? Try writing it yourself.
