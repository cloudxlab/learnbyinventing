# ON SCREEN:
# Part 6: Upsampling to a Non-Integer Scale — 50x50 to 150x150
# ---
Up to now we've been scaling by whole numbers, like doubling or tripling the size. But what if we want to go from fifty by fifty up to one fifty by one fifty? That's three times bigger, so it sounds easy. Think about what could still go wrong, and how you'd decide which original pixel each new one should look at. Give it a try yourself first.
