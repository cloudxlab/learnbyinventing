# Part 2: Color Channels Grayscale

Now let's talk about color. A grayscale image is just one grid of brightness numbers, but a color image has more going on. Think about it: how could you describe a color using only numbers? Take a moment to guess before we dig in. Once we've figured out how color gets stored, we'll see how to boil it back down to gray.
