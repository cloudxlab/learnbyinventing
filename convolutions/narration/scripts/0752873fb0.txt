# Before coding reason about one pixel. Pixel has value 240 . Its eight neighbors are all around 52 . Is 240 likely a real part of the image, or noise? What value should pixel (50, 73) have? How would you compute a better value using the neighborhood?
# ---
Here's a noisy pixel to think about. It sits at row fifty, column seventy-three, and its value is two hundred forty. But every one of its eight neighbors is hovering around fifty-two. So take a second and ask yourself: is that bright pixel really part of the picture, or is it just noise? Then think about what value it *should* have, and how you could use the neighborhood to figure that out. Try reasoning it through on paper first.
