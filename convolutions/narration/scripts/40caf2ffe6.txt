Until now we've worked in grayscale, but real photos are color, which means three layers stacked together: red, green, and blue. So how should a convolution handle that? Here's the first idea: run the same kernel on each color layer separately, then stack the results back together. Try writing it yourself, then test it with a couple of different kernels. And think about when you'd want a different kernel for each channel.
