# Invert Dict Write that returns a new dictionary with keys and values swapped. Assume all values in are unique (otherwise some keys would be lost). [code block]
# ---
Here's a fun twist: what if you want to look things up the other way around? Say you've got names mapped to ages, but now you'd like to start with an age and find the name.

Your job is to write a function that returns a brand-new dictionary with the keys and values swapped. Think about what happens to each pair as you walk through them. And notice we're assuming all the values are unique. Why might duplicates cause trouble? Give it a try!
