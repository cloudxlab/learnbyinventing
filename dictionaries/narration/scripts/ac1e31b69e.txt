# How a dict works inside: Hash the key to a bucket index one arithmetic step Go directly to that bucket Collisions: each bucket keeps a short list to check That s why takes the same time whether the dict holds ten keys or ten million. This is called O(1) constant time.
# ---
Here's the secret behind why dictionaries feel so fast. When you give Python a key, it doesn't search through everything. It runs the key through a hash, which turns it into a bucket number with one quick bit of arithmetic. Then it jumps straight to that bucket.

Sometimes two keys land in the same bucket. That's fine, because each bucket just keeps a short list to check.
