Here's a fun puzzle: how can a computer tell that "listen" and "silent" are anagrams? Try to find one thing that's identical for every anagram of a word. Think about what happens if you put the letters in order. Write a function that returns that sorted string, and use the hint if you get stuck. Give it a go before moving on.
