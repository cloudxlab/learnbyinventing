# Part 0: Dictionary Basics Before coding the exercises, make sure you are comfortable with the four core operations.
# ---
Before we start inventing, let's make sure the basics are solid. A dictionary is just a way of storing information so you can look things up by a name, instead of by a position. There are four core operations you'll use constantly: creating one, adding or changing entries, looking things up, and removing them. Take a moment to get comfortable with each.
