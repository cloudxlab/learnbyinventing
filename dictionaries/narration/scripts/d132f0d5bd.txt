# Invert Dict Write that returns a new dictionary with keys and values swapped. Assume all values in are unique (otherwise some keys would be lost). [code block]
# ---
Here's a fun one. You've got a dictionary where each name points to a value, and now you want to flip it, so the values become the keys and the keys become the values. Before you write anything, picture a tiny example on paper and work out what the flipped version should look like. Then give it a try yourself. Notice why the problem says the values must be unique. What would go wrong if two keys shared the same value?
