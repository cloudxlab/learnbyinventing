# ON SCREEN:
# Group By Write that groups items from a list by the result of applying to each item. This is a generalisation of both and the expense grouping pattern. [code block]
# ---
Here's a challenge that pulls together two things you've already built. Remember the word-grouping and the expense grouping? They felt like different problems, but they share the same skeleton. Now you're going to write one general function that does both. Take a list and a rule, and sort every item into a group based on what the rule says about it. Think about what the keys should be, and what each value should hold. Give it a go yourself before you look at any hints.
