# ON SCREEN:
# Write that returns the value if the key exists, or if it doesn t.
# ---
Now let's put dictionaries to work with a tiny safety net. Imagine you ask for a key that isn't there. Normally Python would complain loudly. Your job is to write a function that looks up a key and hands back the value if it exists. If the key's missing, it returns a friendly fallback instead of crashing.

Give it a try yourself first.
