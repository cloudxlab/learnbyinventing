# Group By Write that groups items from a list by the result of applying to each item. This is a generalisation of both and the expense grouping pattern. [code block]

Here's a challenge that pulls together a lot of what you've built. Think back to word counting, anagram grouping, and the expense tracker. They all did the same thing: sort items into buckets based on some rule. Now write one general function where you pass in the list and the rule, and it does the grouping. Give it a try yourself before moving on.
