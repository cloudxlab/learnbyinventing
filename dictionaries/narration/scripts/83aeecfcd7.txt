# Quick Check: Two different keys hash to the same bucket (a collision). What happens? A. The second key silently replaces the first B. Python raises an error C. The bucket stores both pairs and lookup checks each one still fast if collisions are rare D. The hash function picks a different bucket
# [Fragment 0]: Answer: C. Each bucket keeps a short list of all key-value pairs that landed there. As long as the hash spreads keys evenly, the lists stay tiny and lookups remain fast.
# ---
That's right, it's C! When two keys land in the same bucket, Python just keeps a small list of pairs there and checks each one. As long as the hash spreads keys out evenly, those lists stay tiny, so lookups stay fast.
