# Now that we have TP=4, TN=4, FP=1, FN=1 what should we measure? The model made 5 positive predictions (TP + FP). What fraction of those were actually positive?
# [Fragment 1]: 4 / 5 = 0.80 This is Recall = TP / (TP + FN) Of all the real positives, how many did I find?
# ---
Four out of five, so 0.80. Of everything the model called positive, 80 percent really were positive. That's what we call precision, since it only looks at the predictions the model made. Recall asks a different question: of all the real positives, how many did we find?
