# Can we combine precision and recall into one number ?
# [Fragment 1]: A few more metrics you ll need: Accuracy (TP+TN) / Total Overall correctness (misleading if imbalanced) TPR TP / (TP+FN) Same as recall used in ROC curves FPR FP / (FP+TN) Of all negatives, how many did I falsely flag?
# ---
Here are a few more measures you'll want in your toolkit. Accuracy is just overall correctness, though it can fool you when one class is much rarer than the other. True positive rate is another name for recall, and false positive rate asks, "Of all the real negatives, how many did I wrongly flag?"
