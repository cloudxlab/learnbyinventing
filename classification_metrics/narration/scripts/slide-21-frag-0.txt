# ON SCREEN:
# Which metric would you optimize? Scenario 1: You re screening patients for cancer. Missing a sick patient (FN) could be fatal. Optimize ___? Scenario 2: You re filtering spam emails. Blocking a real email (FP) is very annoying. Optimize ___?
# [Fragment 0]: 1. Recall catch every positive, even if some healthy patients get extra tests. 2. Precision only block when sure, even if some spam slips through. The right metric depends on the cost of each type of error.
# ---
Recall is the answer for the cancer screening. We'd rather catch every sick patient, even if a few healthy people get extra tests. For spam, precision wins, because we only want to block an email when we're sure. The best metric always depends on which mistake costs you more.
