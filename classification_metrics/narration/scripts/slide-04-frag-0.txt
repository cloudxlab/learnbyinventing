# Each prediction has two properties: What was the actual label? (0 or 1) What did the model predict ? (0 or 1) That gives 2 2 = 4 possible outcomes. Try arranging them in a table rows for actual, columns for predicted.
# [Fragment 0]: Predicted 0 (Negative) 1 (Positive) Actual 0 TN True Negative FP False Positive Actual 1 FN False Negative TP True Positive This is called a confusion matrix . Green = correct, Red = errors. The first word says if the prediction was right (True) or wrong (False). The second is what the model predicted (Positive or Negative).
# ---
That grid is called a confusion matrix, and it's simply a way to sort every prediction into one of four buckets. The first word tells you whether the model got it right, and the second tells you what it predicted. So a true positive means it said "yes" and was correct, while a false positive means it said "yes" and was wrong.
