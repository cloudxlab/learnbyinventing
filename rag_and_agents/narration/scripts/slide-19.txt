# The model produces structured text that describes what tool to call. You have to parse that text and actually run the tool. The model is a reasoning engine, not an execution engine. You are the executor. What you invented: the concept of tool use (also called function calling ) — the mechanism that allows language models to request external actions.
# ---
So here's the key idea: the model never actually runs anything. It just writes out structured text saying which tool it wants and what to give it. Your code has to read that text and do the real work. The model is the thinker, and you're the doer. That's what you just invented: tool use, also called function calling.
