Here's a challenge for you: can you build a tiny agent that answers questions from a private knowledge base? A language model can't do that on its own, because it's never seen your documents. And one search often isn't enough when a question needs several facts stitched together. So your agent should search, decide whether it has enough, and search again with a better query if it doesn't. It should answer only from what it found. If you've got a plan, go ahead and try it. If not, the next slides will walk you through it, one step at a time.
