# ON SCREEN:
# The model is sandboxed . It cannot interact with the outside world. It can only process text and return text.
# ---
Here's a thought to sit with: the language model lives in a sealed box. It can't browse the web, open your files, or check today's weather. All it can do is read text and write text back.

So if we want it to actually do things in the world, we've got a puzzle on our hands. Take a moment and think about how you'd solve it.
