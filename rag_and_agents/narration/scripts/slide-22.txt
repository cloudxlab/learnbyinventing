# The Reasoning Loop An agent is a loop where: The model receives the question and any previous tool results. It decides: do I have enough information to answer, or do I need a tool? If it needs a tool, you run it, add the result to the conversation, and go to step 1. If it has an answer, return it. Your task. Build — a multi-turn agent using a conversation history list. At each step, ask the model, parse the response, and either run a tool (appending the result back to the conversation) or return the final answer. Test with questions requiring different numbers of steps: — 1 step — 1 step — 2 steps — 3 steps
# ---
Now we're putting it all together. An agent is just a loop. The model looks at the question and anything it's learned so far, then decides: do I know enough to answer, or do I need a tool? If it needs one, you run it, add the result to the conversation, and ask again.

Your job is to build that loop yourself, using a conversation history list. Then test it on questions needing one, two, and three steps. Give it a try before moving on!
