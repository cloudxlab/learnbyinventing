# Going Further Once you have completed all exercises, the natural next steps are: Proper vector databases, The ReAct paper, Anthropic's native tool use, Evaluation, Multi-agent systems.
# ---
Once you've finished the exercises, here's where to go next. First, swap your in-memory index for a real vector database like ChromaDB or Qdrant. Both are free and run locally. Second, read the ReAct paper by Yao and colleagues. It describes the exact loop you built in exercise five one. Third, try Anthropic's native tool use. The API supports structured tool calling, so the model returns clean JSON instead of the text protocol you invented. Fourth, build an evaluation set: ten questions with known answers, and measure how often your agent gets them right. And fifth, think about multi-agent systems. What if one agent handled retrieval and another handled calculation, with a coordinator deciding which to call? That's the current frontier.
