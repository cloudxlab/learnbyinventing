Part 1: The Amnesiac Oracle

Part 2: Stuffing the Prompt

The simplest fix: paste the document into the prompt.

You cannot stuff 10,000 documents into the prompt. You need a smarter approach: send only the relevant ones.

Instead of sending all documents, find the relevant one first, then send only that one to the model.

But how do you decide which document is relevant? The simplest idea: keyword matching.

Part 3: When Words Lie

Build a tiny keyword search engine and watch it fail:

The key idea: What if you could turn the meaning of a sentence into a list of numbers?

Two sentences that mean the same thing produce similar lists of numbers. These number lists are called embeddings.

But how do you measure “similar” between two lists of numbers?

def semantic_search(query, corpus):
    q_vec = model.encode([query])[0]
    c_vecs = model.encode(corpus)
    scores = []
    for i, c_vec in enumerate(c_vecs):
        scores.append((dot_product(q_vec, c_vec), corpus[i]))
    scores.sort(reverse=True)
    return scores

for score, doc in semantic_search("hotel allowance", MINI_CORPUS):
    print(f"{score:.3f}  {doc[:60]}...")

def chunk_document(text, chunk_size=100, overlap=20):
    words = text.split()
    chunks = []
    start = 0
    while start < len(words):
        chunks.append(" ".join(words[start : start + chunk_size]))
        start += chunk_size - overlap
    return chunks

chunks = chunk_document(DOC_A, chunk_size=60, overlap=15)
print(f"{len(chunks)} chunks")

Build three tools the model cannot do itself:

import datetime

def get_current_date():
    return str(datetime.date.today())

def calculate(expression):
    allowed = set("0123456789+-*/()., ")
    if not all(c in allowed for c in expression):
        return "Error: invalid expression"
    return str(round(eval(expression), 4))

def days_until(date_str):
    target = datetime.date.fromisoformat(date_str)
    return str((target - datetime.date.today()).days)

These are plain Python. The model doesn’t know they exist. You need a protocol — a way for the model to ask you to run a tool.

def parse_response(text):
    lines = text.strip().split("\n")
    if lines[0].startswith("TOOL:"):
        name = lines[0].replace("TOOL:", "").strip()
        inp = lines[1].replace("INPUT:", "").strip() if len(lines)>1 else ""
        return ("tool", name, inp)
    elif lines[0].startswith("ANSWER:"):
        return ("answer", lines[0].replace("ANSWER:", "").strip())
    return ("unknown", text)

def run_tool(name, inp):
    if name == "get_current_date": return get_current_date()
    elif name == "calculate":     return calculate(inp)
    elif name == "days_until":    return days_until(inp)
    return f"Unknown tool: {name}"

def run_agent(question, max_steps=5):
    messages = [{"role": "user",
                 "content": TOOL_PROMPT + "\nQuestion: " + question}]
    for step in range(max_steps):
        r = client.chat.completions.create(
            model="gpt-4o-mini", max_tokens=150,
            messages=messages)
        text = r.choices[0].message.content.strip()
        messages.append({"role": "assistant", "content": text})
        result = parse_response(text)
        if result[0] == "answer":
            print(f"[step {step+1}] ANSWER: {result[1]}")
            return result[1]
        elif result[0] == "tool":
            tool_result = run_tool(result[1], result[2])
            print(f"[step {step+1}] {result[1]}({result[2]}) -> {tool_result}")
            messages.append({"role": "user",
                "content": f"Tool result: {tool_result}\n"
                           f"ANSWER if done, or call another tool."})

def remember(key_value):

    memory_store[key.strip()] = value.strip()

Use a plain dict. remember parses "key=value" with split("=", 1). recall does dict.get(key, fallback).

What you just invented: the agentic loop — the core architecture of every AI agent. Also known as the ReAct pattern (Reasoning + Acting).

The model itself is stateless. But the system around it — the message history, the tool dispatcher, the memory store — gives it the ability to reason over multiple steps, remember context, and take actions.
