# ON SCREEN:
# Assign Codes from the Tree - assign_codes recursive exercise with hints
# ---
You've built the tree. Now you need to walk it to assign the actual binary codes. Write a recursive function called assign_codes. If you reach a leaf, that's a symbol, return a dictionary mapping that symbol to the current prefix. If you reach an internal node, which is a tuple of left and right, recurse on both: go left with prefix plus zero, go right with prefix plus one. Merge the two dictionaries and return. Don't forget the edge case: if there's only one symbol in the whole alphabet, give it the code zero. Check the hints if you need a refresher on how dictionary merging works in Python.
