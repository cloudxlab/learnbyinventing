# ON SCREEN:
# Design the Encoding - exercise with encode_ab and decode_ab functions, hints included
# ---
Here's your first exercise. You need to pick what each letter becomes as a bit string. With two symbols and two possible one-bit strings, zero and one, the natural choice is A maps to zero and B maps to one. Try encoding the message A A B B A by hand. You should get zero zero one one zero. Now decode it back. Does it work perfectly? Great. Now write two functions: encode_ab, which takes a string of As and Bs and returns a binary string, and decode_ab, which does the reverse. If you get stuck, open the hints below the exercise.
