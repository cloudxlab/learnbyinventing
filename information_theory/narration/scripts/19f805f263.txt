# decode(encoded_data, scheme) - generalized decoder exercise with hints
# ---
Now write the matching decoder. It takes the encoded bit string and the code scheme. First build a reverse lookup, flipping the dictionary so bit strings map to symbols. Then walk through the encoded data one bit at a time, building up a buffer. Each time the buffer matches a codeword in your reverse dictionary, output the symbol and clear the buffer. Before you code, think about this: why does the prefix-free property guarantee this will always work? Could two different symbols ever match at the same point? The hints will help with the implementation if you need them.
