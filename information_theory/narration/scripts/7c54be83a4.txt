# ON SCREEN:
# Build the Tree by Hand - trace Huffman tree construction with 4 symbols, with hints
# ---
This is a key exercise. You have four symbols with frequencies: A at fifty percent, B at twenty-five, C at twenty, and D at five. Your goal is to build a binary tree where each leaf is a symbol. You assign codes by tracing from the root to each leaf, zero for left and one for right. Symbols deeper in the tree get longer codes. Start by combining the two symbols with the lowest frequencies. Which two are smallest? Then treat that pair as a single super-symbol and look at what's left. Keep combining until everything merges into one tree. Draw it out and figure out what code each symbol gets. The hints will guide you through the merging steps.
