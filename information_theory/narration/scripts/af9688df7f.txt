# Reflection - 5 open-ended questions about prefix-free codes, Huffman, entropy, real-world uses
# ---
Take a few minutes to answer these reflection questions in your own words. Why must a code be prefix-free? What happens during decoding if it isn't? Why does giving shorter codes to common symbols save bits? Explain the Huffman tree-building process in plain English. What is entropy, and why can't any lossless code beat it? And finally, where is Huffman coding used in the real world? Think about file formats and media you use every day. Writing out your answers will help solidify everything you've learned.
