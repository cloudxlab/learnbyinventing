# Check for Ambiguity - is_prefix_free exercise with hints
# ---
Now here's a tricky question. What if you chose A equals zero and B equals zero zero? Try encoding A B. You get zero zero zero. But wait, B A also gives zero zero zero. The same bit string means two different messages. That's a disaster for decoding. The fix is a rule called prefix-free: no codeword can be the start of another. Zero is the start of zero zero, so that code fails the test. Your task is to write a function called is_prefix_free that takes a dictionary of symbol-to-bits mappings and checks whether the code is prefix-free. The hints will help if you need them.
