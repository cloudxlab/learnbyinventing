# Why One Bit Each No Longer Works - fixed-width encoding for 3 symbols, with hints
# ---
Now we have three symbols: A, B, and C. With one bit you can only represent two things, zero or one. Three symbols don't fit, so at least one must get a longer code. The simplest solution is to give every symbol exactly two bits: A is zero zero, B is zero one, C is one zero. We just skip one one since it's unused. Write encode_fixed and decode_fixed using this scheme. Encoding is straightforward, look up each letter. For decoding, read exactly two bits at a time. Check the hints if you get stuck.
