Here's a small problem to start with: if we want to store the symbols A and B as bits, how do we tell them apart? The answer is to give each symbol its own unique bit pattern. We call that a code, and each pattern is a codeword.

Look at the code we've got here. Take a second and think about what it means to send a message with it. Does it feel like enough to decode everything unambiguously?
