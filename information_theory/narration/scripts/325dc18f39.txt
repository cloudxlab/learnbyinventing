# Average Bits Per Symbol - avg_bits exercise with hints

Now let's figure out how to measure whether one encoding is better than another. If every symbol uses two bits, the average is obviously two. But with variable-length codes, A might cost one bit and appear half the time, while B costs two bits and appears a quarter of the time. The key idea is a weighted average: multiply each symbol's frequency by its code length, then add them all up. Try it by hand first with the numbers on screen. Then write a function called avg_bits that takes a scheme and frequencies and returns the average. The hints will give you the formula if you need it.
