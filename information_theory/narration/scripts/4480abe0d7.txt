# ON SCREEN:
# Measure on Real Data - generate 1000-symbol message and test schemes
# ---
Theory is nice, but let's see it in practice. Generate a random message of a thousand symbols using the given frequencies, then encode it with each of the three schemes and count the total bits. Does the scheme that wins match the one with the lowest average bits per symbol? This is a great way to build intuition: the theoretical calculation and the real measurement should agree closely.
