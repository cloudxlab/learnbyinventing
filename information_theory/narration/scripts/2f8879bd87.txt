# ON SCREEN:
# With four symbols A, B, C, D appearing at known frequencies, how do we measure how good a code is? Symbol Frequency A 50% B 25% C 20% D 5%
# [Fragment 0]: The average bits per symbol : weight each codeword s length by how often the symbol appears.
# ---
Here's the question: with symbols showing up at different rates, how do we score a code? We take the average bits per symbol. We weight each codeword's length by how often that symbol appears, so common symbols count for more.
