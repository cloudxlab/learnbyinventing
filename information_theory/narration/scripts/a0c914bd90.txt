Here's a smarter idea. What if A gets just one bit, zero, and B gets one zero, and C gets one one? That way A uses only one bit instead of two. And it's still prefix-free: zero doesn't start with one, so it can't be confused with one zero or one one. But now decoding is trickier, because you can't just read two bits at a time. Instead, you walk through the bit string one bit at a time, building up characters in a buffer. When the buffer matches a known codeword, you output the symbol and clear the buffer. Write encode_var and decode_var using this scheme. The hints below will walk you through the decoding logic if you need help.
