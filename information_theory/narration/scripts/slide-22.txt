Now it's time to put everything together. Write one function, `encode`, that takes your data and the symbol frequencies. Inside, it should build the Huffman scheme, then use that scheme to turn the string into bits, and finally return the encoded result. You've already built every piece, so this is just connecting them. Give it a try before moving on.
