Now turn that hand process into code. Represent each leaf as a string and each internal node as a tuple of its two children. Start with a list of frequency-symbol pairs, sorted by frequency. Pop the two smallest, combine them into a new node whose frequency is the sum, and push it back. Repeat until one item remains. That's your tree. The function should take a dictionary of frequencies and return the tree structure. Three hints are available if you need help with the data structure or the loop logic.
