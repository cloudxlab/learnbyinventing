# Information-Theoretic Lower Bound (Entropy) - entropy exercise with log2 formulas and hints
# ---
Here's something beautiful. Look at the pattern: A appears half the time and gets one bit. B appears a quarter of the time and gets two bits. The ideal code length for a symbol with frequency p is log base two of one over p. That's exactly the number of bits it "deserves." If you compute the weighted average using these ideal lengths instead of actual code lengths, you get something called entropy. It's the absolute theoretical minimum, the fewest average bits per symbol any lossless code can achieve. Write a function called entropy and compare its output to your Huffman average. You'll see Huffman gets very close. The hints will show you the formula.
