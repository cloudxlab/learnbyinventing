# Huffman coding is provably optimal among all codes that assign a fixed bit-string to each symbol.

Here's something worth pausing on. The code you built, Huffman coding, isn't just a good idea. It's provably the best you can do if every symbol gets its own fixed bit-string. No cleverer tree exists. Nobody can beat it with that rule. Still, that rule leaves a little room, and that's where we're headed next.
