# ON SCREEN:
# encode(data, frequencies) - generalized encoder exercise with hints
# ---
Time to put it all together. Write a function called encode that takes a data string and a frequency dictionary. It should build the Huffman scheme from the frequencies, then encode the data by looking up each character's code and joining them, and return both the encoded bit string and the scheme. That way the caller has everything needed for decoding. This function is really just gluing together the pieces you've already written. Check the hints if you need a reminder.
