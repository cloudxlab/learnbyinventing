# Find New Centers You have two groups. The centers you started with were arbitrary — just the first two points. Now that you have groups, can you find better centers? What single point best represents a group of points? Write that returns a new list of centers — one per group.
# ---
You've got two groups now, but remember, the centers we started with were just the first two points. They were arbitrary. So here's a question: if you had to pick one single point to represent an entire group, which point would it be? Think about what "in the middle" really means for a bunch of points. Then write a function that gives back a new center for each group. Give it a try yourself first.
