# Measuring Cluster Quality How tight are your clusters? One measure: for each point, compute its distance to its center. Sum up all these distances. A lower total means tighter clusters. Write that returns this total.
# ---
Now that you've built clusters, here's a natural question: how good are they? Think about a point and its center. If the point sits close, the cluster is tight. If it's far away, not so much.

So try writing a function that measures each point's distance to its center, then adds them all up. A smaller total means tighter clusters. Give it a go yourself first!
