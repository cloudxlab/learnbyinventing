# Quick Check: You run K-Means twice on the same points but with different random starting centers. What happens? A. Always the same result K-Means finds the unique best answer B. Right, it's B. Where the centers start can change where they end up, because K-Means can settle into different local optima. So in practice, run it a few times with different random starts and keep the best result.
