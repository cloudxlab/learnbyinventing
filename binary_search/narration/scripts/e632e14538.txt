Let's see what you built. count_halvings is log base 2 — the foundation of O of log n complexity. sqrt_binary_search is numerical square root via bisection. nth_root generalizes to any root. log_base_n searches for an exponent. contains and find_first are classic binary search on sorted arrays. And find_min_convex uses the same halving idea that gradient descent relies on.
