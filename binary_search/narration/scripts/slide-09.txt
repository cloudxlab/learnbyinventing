# ON SCREEN:
# Nth Root Write that returns the real nth root of x. For simplicity, assume x ≥ 0 (handle negatives as a bonus below).
# ---
Square roots were one thing, but what about cube roots, fourth roots, any root at all? Now we're generalizing. Your function takes two inputs, the number and which root you want, and returns the real answer. Think about what you changed between square root and cube root, and what has to change again. Give it a try yourself first.
