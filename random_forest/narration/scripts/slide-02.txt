Here's a challenge: can you invent one number that tells us how spread out a bunch of values are? It should be zero when every value is identical, and it should grow as the values drift apart. Pause here and try writing your own formula before you read on. Then we'll compare it with the classic answer, variance. It uses squared distances so that misses above and below the mean can't cancel each other out.
