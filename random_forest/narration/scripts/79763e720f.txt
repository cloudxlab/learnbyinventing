Trying splits by hand does not scale. Write a function called find_best_split that takes X, y, and an optional feature_indices parameter. It should consider every feature index, or only the given subset. For each feature, take the midpoints between consecutive sorted unique values as candidate thresholds. For each candidate, split the targets into left and right and compute the variance reduction. Return the best feature, threshold, and reduction. If there is nothing to split, return None, None, zero.
