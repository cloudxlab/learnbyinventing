# Bootstrap Sampling (randomize the *rows*) Give each tree its own dataset by sampling rows from the original rows with replacement --- some rows appear twice, some not at all. This is called a bootstrap sample . Write that returns a new of the same length, where each position holds a uniformly random row of the original data --- and each stays paired with its row. Use .
# ---
Now we're giving every tree its own slightly different dataset, and here's the trick. Imagine drawing rows out of a hat, but you put each one back after you pick it. Some rows show up twice, and some never get picked at all. Before you code it, think about how you'd keep each row paired with its label. Give it a try!
