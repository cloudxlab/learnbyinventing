# ON SCREEN:
# Quick Demo with re.search, re.findall, raw strings
# ---
Let's see Python's regex module in action. The re.search function finds the first match anywhere in the text, while re.findall returns every match as a list. Notice the r before the pattern string -- that's a raw string, which tells Python not to treat backslashes specially. Always use raw strings for your regex patterns. Try running these examples yourself.
