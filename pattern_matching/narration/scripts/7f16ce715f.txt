# ON SCREEN:
# Character by Character exercise with match_exact, base cases, hints
# ---
Let's start with the simplest kind of matching: is this pattern exactly the same as this text? But here's the catch -- you can't use equals-equals on the whole string. You have to go one character at a time. Why? Because soon, some pattern characters will have special meanings, and whole-string comparison won't work anymore. Think recursively: two strings match if their first characters match and the rest match too. What are your base cases? If you get stuck, there are hints below the exercise.
