# Think Before You Code - star wildcard branching with hints
# ---
Here's the tricky part. When the pattern says star, how many characters should it swallow? You can't know yet -- it depends on what comes after the star. So don't decide! Instead, try both options and let recursion explore. Option one: the star swallows nothing. Option two: the star swallows one more character. If either branch succeeds, the whole match succeeds. This is the beautiful idea at the heart of pattern matching. There are hints below to help you work it out.
