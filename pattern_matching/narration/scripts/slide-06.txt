# Part 3: The `*` Wildcard The big one: matches zero or more characters -- any characters. [code block]
# ---
Now for the big one: the star wildcard. Unlike the question mark, which matches exactly one character, the star can match zero, one, or many characters, whatever they happen to be. That changes things. Before we write any code, think about it: how would you even know where the star should stop matching?
