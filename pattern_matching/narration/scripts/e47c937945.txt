# Add ? to Your Matcher exercise with match_q, progressive hints

Now upgrade your matcher. The question mark in a pattern matches exactly one character -- any character at all. Write match_q, which is your match_exact with one extra case. When the first pattern character is a question mark, what changes? You don't need to compare it to the text character anymore -- just make sure the text isn't empty, then recurse on the rest. Check the hints below if you need a nudge.
