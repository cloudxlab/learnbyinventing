Welcome! Every time you search for a file, check that an email address is valid, or dig through a server log, a pattern matcher is quietly doing the work. In this chapter, you'll invent one yourself. We'll start with exact matching, add wildcards, then use recursion to handle the trickiest one. Finally, we'll mine a real server log with Python's built-in tools.
