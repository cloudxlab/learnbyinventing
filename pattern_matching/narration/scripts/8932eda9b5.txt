# ON SCREEN:
# Mine a Real Server Log - find_urls and domain_counts with hints
# ---
Now let's put it all together on real data. You have genuine lines from an Apache web server access log. First, write find_urls to extract every H-T-T-P or H-T-T-P-S URL. A URL ends where whitespace, a quote, or a closing parenthesis begins -- a negated character set handles that. Then, write domain_counts to tally up which domains appear most often. This is the same word-counting pattern from the Dictionaries chapter, just applied to URLs.
