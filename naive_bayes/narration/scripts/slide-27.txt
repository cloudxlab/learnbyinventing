Now that we understand the math, it's time to turn it into a real class. But before we write any code, let's pause and design it. Think about what the model needs to remember after training, so it never has to re-scan the data. You'll want the possible labels, how often each label appeared, and how often each feature value showed up with each label. You'll also need to know how many distinct values each feature has, for smoothing. Try filling in that design yourself first.
