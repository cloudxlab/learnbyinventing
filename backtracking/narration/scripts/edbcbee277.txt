# Exercise: find_first_empty_space. Scan the Sudoku board for the first cell containing 0. Return (row, col) or (None, None) if the board is full.
# ---
Here's your first Sudoku helper. Write a function that scans the board top to bottom, left to right, and returns the position of the first empty cell, meaning the first zero. If the board is completely filled, return None, None. That will be our signal that the puzzle is solved. This one is straightforward: just a nested loop.
