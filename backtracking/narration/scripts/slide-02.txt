# ON SCREEN:
# handshakes Write that returns the list of all unique pairs as tuples. A pair should appear once: if is in the list, must not be. [code block] Think: for people, how many handshakes will there be? Test your formula with the last assertion.
# ---
Here's a fun puzzle to start with. Imagine a room full of people, and everyone shakes hands with everyone else exactly once. Your job is to write a function that lists every unique pair. If Alice shaking hands with Bob is already on the list, Bob shaking hands with Alice shouldn't show up again. Before you code, try a small group on paper. How many handshakes do you get with three people? Four? Five? See if you can spot a pattern and turn it into a formula. Then use that last assertion to test your idea.
