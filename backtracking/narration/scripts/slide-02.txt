# Part 1: Warm-Up — Enumerating Pairs A room of people all shake hands, each pair exactly once.
# ---
Let's start with a warm-up that sounds simple. Picture a room full of people, and every pair shakes hands exactly once. No repeats, no one skipped. Before you write any code, think about how you'd list every handshake. Which pairs would you write down, and in what order? Give it a try yourself first.
