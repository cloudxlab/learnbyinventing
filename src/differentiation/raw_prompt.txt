--- Part 1: Numerical Differentiation (2026-11-11) ---

Let's create separate slides for differentiation on the same format and
philosophy - learnbyinventing. 1. Show a rectangle box which has input x and
output y. Inside the box it show y = 2x. ask the value of y1 and y2 at
x1 = 1 and x2 = 1.01. How much is (y2-y1)/(x2 - x1) ?

Now add in the end - this is called differentiation or derivative of y wrt to
x or dy/dx or deltay/delta x. Next add: Now, let us take another function
y = 3x. Ask user to find y at x = 1 and then slightly increase x by say
.000001 and find value of y. You can define a python function for y = 3x and
use that to do these calculations. Now, find (y2-y1)/(x2 - x1). Afterwards,
show the answers and congratulate user for doing right. Next ask user to
define a python function for x^2 and ask user to find the derivative of this
function at x = 1, -1, 0 and 2. Next ask user to put together the code to
compute derivatives in a python function diff(my_func,x).

--- Part 2: Algebraic Differentiation (2026-11-12) ---

Now, add slides on algebraic differentiation or analytical differentiation.

Take y = x**2, Ask them to compute y2 at x + d and then ask them to compute
(y2-y1)/(x2 - x1)…

And then show them dy/dx = 2*x + d . Ask them to ignore d.. dy/dx = 2x

Ask them to compute derivative of various other algebraic functions such as
y = 10, y=5x + 6, y = 3x^2 +2

--- Part 4: Partial Derivatives (2026-11-12) ---

Now, add slides of Partial Derivatives. Show a block taking two inputs x1 and
x2. And the the equation being y = x1^2 + 2 * x1 *x2.

Define partial derivatives. Ask the user to calculate the algebraic
differentiation first and then calculate the numeric differentiation dy/dx1
and dy/dx2 at x1=1 and x2=1; x1=2, x2=1.5..

And then ask the user to write a function diff2(my_func, x1, x2) that returns
the partial derivatives wrt x1 and x2.

--- Part 5: N-Input Functions & Gradient (2026-11-12) ---

Add slides on calling a function with many arguments using a list - i.e.
turning list into arguments of a function.

Now, ask user to create a function to compute all partial derivates of a
function having many arguments diffn(my_func, arr). Show example use of diffn
on a function that take three arguments and four arguments.

--- Part 6: Chain Rule (2026-11-12) ---

Now, add slides for chain rule or a function of function of function.

Create a block diagram having two blocks x —> block1 (z = 2*x + 5) —>
block2 (y = z^2 ) —> y

Let user create two functions zz(x): 2x+5 and yy(z*z).

First compute y and z at x = 1 using these two functions.

Now, let them compute dz/dx and dy/dz at x = 1 numerically. Then ask if they
can compute dy/dx given dy/dz and dz/dx? Give the hint of calculation
dy/dx = dy/dz * dz/dx

Now, ask user create a function yz(x) which takes x and returns y by using
the two functions zz and yy. And let them compute the numeric derivative of
this function at x = 1 and let them compare the results.

[Follow-up: Instead of just handing out the two functions yy and zz, let the
user create them. Give the specs.]
