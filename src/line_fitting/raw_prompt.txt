Create presentation for teaching a class 'line fitting' and curve fitting by the way of learn by inventing:

1. Show a block diagram where input is x and output is y. And display the following question next to it:
when x was 1, y was 3 and when x was 2, y became 7, how much will be y when x will be 3?

Display the x, y as a table and put x=3, y=? as last row.

Display another questions on clicking next:
    * That right! It is y = 11
    * how much will be y when x will be 2.5?
      [add x=3, y=11 and x=2.5, y=? in the table]

Continue the progressive reveal:
    * x=2.1 → y=7.4 (just 0.1 past x=2, so 7 + 0.4)
    * x=0 → y=-1 (going back from x=1 subtracts 4)
    * x=0.5 → y=1 (halfway between -1 and 3)
    * x=x₁ → y=4x₁-1 (the general formula)

Each step: show the answer with congratulations, update the table, ask the next question.
Final reveal: y = 4x - 1 — "You just discovered a linear function!"

2. Finding the pattern, discovering y = mx + c
3. Writing predict(m, c, x) and fit(x1, y1, x2, y2)
4. What if data doesn't fit a line? Curve fitting.
5. Measuring fit quality.
