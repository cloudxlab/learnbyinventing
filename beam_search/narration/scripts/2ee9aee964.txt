# Now use temperature in text generation. We need to convert the LLM s probabilities to logits (log-probabilities) first, then apply temperature, then sample:
# ---
Now let's put temperature to work in real text generation. Here's the catch: a language model hands us probabilities, but temperature works on logits, which are just the log of those probabilities. So first we take the log, then divide by temperature, and then sample from the result. Give it a try yourself before moving on.
