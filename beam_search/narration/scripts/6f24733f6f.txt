# What if Heads should come up 70% of the time? Before coding: if gives a number between 0 and 1, what threshold should you use instead of 0.5?
# ---
Here's a twist: what if the coin isn't fair? Say Heads should come up seventy percent of the time. Our random number is still somewhere between zero and one, so before you write any code, think it through. Where would you draw the line now? Grab a pencil and picture that range as a stick, then figure out how much of it should count as Heads. Give it a shot yourself first.
