# What if Heads should come up 70% of the time? Before coding: if gives a number between 0 and 1, what threshold should you use instead of 0.5?
# [Fragment 0]: Use 0.7 as the threshold. Numbers below 0.7 (which happens 70% of the time) become Heads.
# ---
Exactly. Since the random number is spread evenly between zero and one, anything below 0.7 happens seventy percent of the time. So that's your new cutoff for Heads. Moving the threshold is all it takes to bias the coin.
