# A large language model (LLM) does something remarkably simple: Given some text, it predicts probabilities for the next token .

Here's something that might surprise you. A large language model does one thing, and it's remarkably simple. You give it some text, and it predicts how likely each possible next piece of text is. That's it. Every chat, every essay, every answer starts from that one small step.
