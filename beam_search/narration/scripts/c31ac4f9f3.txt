# A large language model (LLM) does something remarkably simple: Given some text, it predicts probabilities for the next token .

Here's something that might surprise you. Under all the hype, a large language model does one remarkably simple thing. You give it some text, and it predicts how likely each possible next token is. That's the whole trick. Hold onto that idea, because everything we've built so far is about to plug right into it.
