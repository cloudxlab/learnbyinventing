# What if Heads should come up 70% of the time? Before coding: if gives a number between 0 and 1, what threshold should you use instead of 0.5?
# [Fragment 1]: Generalize: write where is the probability of Heads.

Think of it as a dial: if you want Heads 70% of the time, set the threshold to 0.7 instead of 0.5. So in general, you'd write "Heads if the random number is less than p," where p is the probability of Heads.
